# 数据层字段口径

> **本目录是全项目唯一的 CSV 读取点。** 只有 `data/loader.py` 允许读这些文件，
> `engine/` 和 `ui/` 一律通过 `loader.py` 的函数拿数据。
> 将来把 CSV 换成数据库或网络接口时，改动只发生在 `loader.py` 一个文件里。

---

## 通用约定

| 项 | 约定 |
|---|---|
| 编码 | **UTF-8 with BOM（`utf-8-sig`）**。用 Excel 另存时选「CSV UTF-8（带 BOM）」，否则中文乱码 |
| 分隔符 | 英文逗号 `,` |
| 多值字段 | 用竖线 `\|` 分隔，例如 `自然\|拍照\|免费` |
| 时间 | 24 小时制 `"HH:MM"`，必须补零（`09:00` 不能写 `9:00`）；全天填 `00:00` ~ `23:59` |
| 空值 | 留空即走代码里的默认值，不要填 `NULL` / `-` |
| 坏行 | `loader.py` 会跳过并打印 `[warn]`，不会让整个程序崩掉 |
| 整表编码 | 先按 `utf-8-sig` 读，失败自动回退 `gbk`（会打印一条 `[warn]`） |

> ⚠️ **两种编码都失败时**，`_read_csv` 会打印 `[error] ... 无法解码` 并返回**空表**（不抛异常，避免页面白屏）。
> 这时你看到的症状是"一个站点都没有"，真正原因在编码 —— 用 Excel 另存为「CSV UTF-8（带 BOM）」即可。
> 另外：如果文件是空表或列名被改过，也会打印 `[error] ... 解析出 0 条 POI`。

改完 CSV 想立刻生效：调用 `loader.clear_cache()`，或重启 Streamlit。

## `pois.csv` —— 兴趣点表

| 列名 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `poi_id` | str | ✅ | — | 主键，全局唯一，建议 `P001` 这样带补零 |
| `name` | str | ✅ | — | 名称 |
| `category` | str | ✅ | — | 分类。取值自由，同一列内保持一致即可 |
| `lat` | float | ✅ | — | 纬度 |
| `lon` | float | ✅ | — | 经度 |
| `open_time` | str | | `00:00` | 开放时间 `"HH:MM"` |
| `close_time` | str | | `23:59` | 关闭时间 `"HH:MM"` |
| `stay_min` | int | | `60` | 建议停留分钟数 |
| `cost` | float | | `0.0` | 人均花费（门票/餐饮），`0` = 免费 |
| `tags` | str | | 空 | 兴趣标签，竖线分隔。与 `PlanRequest.interests` 经 `interest_alias` 匹配 |
| `score` | float | | `0.5` | 静态质量分 `0~1`，由数据给出（不是引擎算的） |

**当前内容是 8 条占位数据**（`占位点01` ~ `占位点08`，坐标与标签均为中性占位）。
场景锁定后**整体替换**这张表即可，代码零改动。

## `travel_matrix.csv` —— 距离/耗时矩阵

| 列名 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `from_id` | str | ✅ | — | 起点 `poi_id` |
| `to_id` | str | ✅ | — | 终点 `poi_id` |
| `mode` | str | | `walk` | 交通方式，取值要出现在场景配置的 `[transport_speed_kmh]` 里 |
| `minutes` | float | | `0.0` | 在途分钟数 |
| `distance_km` | float | | `0.0` | 距离（km） |
| `cost` | float | | `0.0` | 交通费用 |

**允许不完整。** 查不到的边会返回 `None`，由 `engine/geo.py` 用「haversine 距离 ÷ 场景速度」估算兜底 ——
所以只填你真正有把握的几条即可，不用凑满 N×N。

查找是**双向**的：矩阵里只写了 `P001→P002`，查 `P002→P001` 也能命中。

---

## 怎么加新数据

1. 用 Excel 编辑，**另存为 → CSV UTF-8（带 BOM）**，覆盖原文件
2. 跑一次 `python -m unittest tests.test_data -v` 确认字段没写错
3. 界面上点「重新规划」（或重启 Streamlit）看新数据
