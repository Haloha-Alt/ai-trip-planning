GETTING STARTED · 30 秒上手

使用指南

三步就能得到一份可以带走的行程，其余设置都可以先不管。

01

写一句话需求

例如「上午去图书馆自习，中午食堂吃饭，顺便取快递，别太赶」。系统会自动解析地点、时间与节奏。

02

点「生成行程」

左侧那个最大的按钮。高校、场景保持自动即可；想细调再展开「高级设置」。

03

看结果 / 导出

右侧可切换行程表、时间轴、地图、算法对比；满意后导出 JSON / Markdown / CSV。

想看得更清楚？ 顶部「主题」下拉有 7 套界面： 浅色 / 深色是基准，纸质、奶蛙、像素、赛博、原神各有不同的按钮位置与大小。
地图 / 提瓦特传送图 顶部「✦ 提瓦特地图」会一键切到原神主题并直接跳到传送图； 点菱形锚点可设为当前传送点，冒险 HUD 上的「显示秘境与神像」会解锁七天神像与秘境。 普通「地图」按钮 / 页签也会自动滚动并高亮地图卡片，不会再点了看不见变化。

模型：自动 or 手动

下拉第一项 自动匹配模型＝按需求难度路由（快 / 推理 / 长上下文 / 看图）。

往下选具体模型＝手动锁定，整次请求都用同一个，结果更可预期。原型内置 21 个演示模型，分「推荐」与「全部模型」两组。

三种算法

贪心：每步选眼前最优，快。2-opt：在贪心基础上交换站点做局部优化。随机：作为基线对照。

「算法对比」用同一份需求跑三遍，直接看满意度 / 成本 / 时间 / 距离的差异。

模型对比 / 体检

「模型对比」把同一句话跑两遍（规则解析 vs 模型解析），看模型到底读懂了什么。

「体检」让模型检查行程里的硬冲突（时间窗、预算、往返）。

导出与分享

结果可导出 JSON / Markdown / CSV；有内网 IP 时会生成一条可直接发给同学的链接。

「清缓存」用于改了站点 CSV 之后重新加载数据。
