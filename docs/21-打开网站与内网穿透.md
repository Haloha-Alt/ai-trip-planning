# 21 · 打开网站 / 让别人用流量也能访问

> 版本 v1.0 ／ 2026-11-03 ／ 三个双击脚本 + 内网穿透四步。
> 三个脚本的内容都是 UTF-8 无 BOM + CRLF（`.bat` 用 LF 会双击一闪而过）。

---

## 二、只给自己看（本机）

双击 **`1-启动网站.bat`** → 浏览器自动打开 <http://127.0.0.1:8000/> → 填需求 → 生成行程 → 切「地图」页签。

- 窗口不能关，关了服务就停。
- 页面显示无法访问：等 2 秒按 **F5**（服务还没起完）。

## 三、让"同一 Wi-Fi 的人"访问

双击 **`分享给他人.bat`**，窗口会打印类似：

```
正在以"可分享"方式启动（端口 8080）
口令：trip-8261
发给别人：http://10.15.49.87:8080/?code=trip-8261
```

对方连同一个 Wi-Fi 就能开。
**校园网可能开了"终端隔离"**（2026-10-31 实测凌水校区就是），同 SSID 也连不上 → 直接走下一节。

## 四、让"任何网络、手机流量"的人访问（内网穿透）

原理：隧道把公网域名转发到你电脑的 8080，对方走 4G/5G 也能开，**不需要同一 Wi-Fi**。

### 四步

**第 1 步（必要）** 双击 **`分享给他人.bat`**
→ 它把服务起在 `0.0.0.0:8080` 并设好口令。**这个窗口要一直开着。**

**第 2 步** 双击 **`3-开穿透.bat`**
→ 它跑 `tools.tunnel`，认得出 cpolar / cloudflared，并打印公网地址。

**第 3 步** 抄下打印出来的地址，形如 `https://xxxx.r8.cpolar.cn`

**第 4 步（强烈建议）** 真打一次接口，确认能开再发人：

```powershell
cd D:\projects\ai-trip-planner
.venv\Scripts\python.exe -m tools.share_link https://xxxx.r8.cpolar.cn --port 8080 --check
```

看到 `公网 … [OK] HTTP 200` 就发这条给对方：

```
https://xxxx.r8.cpolar.cn/?code=trip-8261
```

> 口令必须带上（`?code=`），否则接口返回 401。链接里已经带了，对方直接点就行。

### 这台机器的两个既成事实（省得你重踩）

| 事实 | 后果 |
|---|---|
| cpolar 已装 `E:\cpolar\cpolar.exe`，authtoken 已配 | 不用注册、不用装 |
| 后台那条隧道的目标端口是 **8080**（不是 8000） | 所以必须用 `分享给他人.bat`（8080），不要用 `1-启动网站.bat`（8000）去配隧道 |

---

## 五、固定域名（可选，约 10 元/年）

免费隧道**每次重启域名就变**，发出去就失效。要一个不变地址：

1. 买个域名（`.top`/`.xyz` 约 10 元/年），NS 托管到 **Cloudflare**；
2. 装 cloudflared，建固定隧道指向 `localhost:8080`；
3. 之后地址永远是 `https://你的域名/?code=口令`。

（完整命令在 `docs/09-上线操作清单.md` 的 C 节。）

## 六、故障对照（按症状查）

| 症状 | 原因 | 处理 |
|---|---|---|
| 公网域名能开，页面 **502** | 隧道指 8080，但服务没起在 8080（用了 8000 那个脚本） | 关掉重开，改用 `分享给他人.bat` |
| 页面能开，但点"生成行程"报 **401** | 链接里没带 `?code=` | 用完整链接；或页面弹框时输口令 |
| 公网打不开、本机能开 | 隧道没开 / 域名抄错 | 重跑第 2 步，照抄打印的地址 |
| 昨天能发，今天失效 | 免费域名变了 | 重新跑第 3–4 步拿新地址 |
| 本机 8000 打不开 | 端口被占（上一个窗口没关） | 关掉旧窗口；或 `-m api.server --port=8010`（**等号**，不是空格） |
| 页面打开但地图灰的 | 高德瓦片还在下载 / Key 失效 | 等 1–2 秒刷新；看 `.env` 的 `AMAP_JS_KEY` |

## 七、安全底线（开放出去之前）

- **必须设 `ACCESS_CODE`**（`分享给他人.bat` 里已经写了 `trip-8261`，自己改一个）；
- 不设 = 任何拿到地址的人都能白嫖学校的大模型额度；
- 演示结束就关掉那两个窗口 —— 隧道和口令都跟着停。
