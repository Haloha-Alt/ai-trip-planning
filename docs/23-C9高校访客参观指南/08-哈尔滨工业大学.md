# 23-08 · 哈尔滨工业大学（一校区为主，另有二校区、深圳校区）——C9 里最好进

> 调研日期 2026-11-04。信源：哈工大官方通知（2024-12-26 框架、2025-07-06 暑期通知），经极光新闻/新浪转载；"哈尔滨工业大学"公众号；本地宝；航天馆/博物馆官方信息；新浪深圳 2025-05、新浪财经 2025-04-14（深圳校区）。**出行前以哈工大公众号最新通知为准——11 月初正常学期内大概率免预约，但临近考试周/寒暑假会切回预约模式。**

## 一、入校（全国最开放的一所）

### 1.1 总体政策
2023 年 8 月在全国率先全面开放；2024-12-26 官方通知明确现行框架：
> **每年寒暑假、劳动节、国庆节、集中考试周实行预约参观；其他时间如无特殊活动，不用预约、不限名额。**

（2025 暑期 7-13 至 8-31 为预约模式；**当前 2026 年 11 月是否处于预约窗口期需查最新通知**。）

### 1.2 预约期规则（公众号"哈尔滨工业大学"→ 服务 → 校园参观预约）
| 类型 | 可约 | 规则 |
|---|---|---|
| **个人** | 当天及未来 7 天 | 凭身份证/港澳台通行证/外国人永居证/护照实名约；最多为同行 3 人代约；儿童须有已约监护人陪同；恶意约拉黑 |
| **团体** | 未来 2–9 天 | 博物馆 ≥10 人、航天馆 ≥20 人为团体；凭**加盖公章的团体参观承诺书原件**走团队通道 |
| **校友** | 随时 | "哈尔滨工业大学校友"小程序领"功夫码"，闸机扫码，可加随行人员 |
| **学生亲属** | — | 学生经哈工大 APP"智行"申请 |

- 入校 **8:30–16:30**，当日 **19:00 前离校**；**全程免费**。
- 个人所乘车辆禁入（停车资源有限）；团体车辆凭预约单入校。

### 1.3 校门（分校区）
- **一校区**（南岗区西大直街 92 号）：西大直街校门（正门）、科学园和兴路校门（和兴路 95 号）。
- **二校区**：黄河路校门。
- 个人刷身份证核验入校；港澳台/外籍走人工通道；团体统一从和兴路门或黄河路门入。

## 二、进校之后怎么逛

### 2.1 交通
- 一校区正门：地铁 1 号线可达（精确对应站待核实）；公交 10/11/31/44/55/81 等。
- 航天馆：公交至"林兴路站"步行至和兴路校门。
- 博物馆（校外）：地铁 1 号线**铁路局站**步行约 100 米。

### 2.2 推荐动线
- **半天**：一校区正门 → 校名石 → 主楼 → 校部楼 → 校训石 → 图书馆（外观）→ 校园暖廊 → 神舟揽月广场 →（校车/步行去科学园）**航天馆** → 卧震苍穹广场。
- **一天**：上午同上 + 二校区（黄河路门入，清泽楼一带）；下午航天馆 2–3 小时；到达/离开当天顺访公司街博物馆。
