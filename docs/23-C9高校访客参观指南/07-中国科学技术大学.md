# 23-07 · 中国科学技术大学（合肥，东区/中区/西区/南区/高新校区）——C9 里最难进

> 调研日期 2026-11-04。信源：包河区政府官网 2025-04 报道、科大保卫与校园管理处公众号（师生亲友进校系统升级公告）、校友总会官网 aga.ustc.edu.cn、2025 科技活动周邀请函（校官网）、档案文博院官网 2026-07、饮食服务集团 2025-05-16 通知、保卫处 bwclf.ustc.edu.cn。**结论先说：科大没有面向纯社会公众的常设入校通道，没校内关系就等科技活动周。**

---

## 一、入校渠道（按有无校内关系分三条路）

### 1.1 总体政策
**未对纯参观的社会公众常设开放。** 校外人员进入主要靠：
1. **师生亲友邀请**（"师生亲友进校系统"）；
2. **校友通道**；
3. **集中公众活动**（科技活动周、校园开放日）。

### 1.2 三条路详解
| 渠道 | 怎么走 | 细节 |
|---|---|---|
| **师生亲友** | "中国科大保卫与校园管理处"公众号或"中国科大"APP 入校核验模块预约 | 系统升级后**取消刷码，改为到已预约校区刷身份证入校**（成功收短信）；仅限师生本人规范使用，转借/营利代约首次违规限约 3 个月，累计 3 次永久封禁。咨询电话 **0551-63600083**。提前量/名额/时段官方未核实（自媒体称提前 1–2 天，别当真） |
| **校友** | "科大人"小程序认证后预约 | 东区/中区/西区/南区/高新**各主要校门设校友通道**，刷身份证或凭证入校，当日有效 |
| **科技活动周（散客唯一正规门）** | 每年 5 月中旬；2025 年为 5-17 | 团体 9:00–17:00（限 14000 人，每校 20–500 人，禁研学机构）；**散客 13:30–17:00（16:00 停止入校），每天 14:00 放 1000 个名额、共 4000 名，约满即止**。覆盖东区/中区/西区/高新，30 余个科普点开放 |
| 公务来访 | 保卫处"车辆人员入校申请"（bwc.ustc.edu.cn） | 需校内对接 |

### 1.3 证件与车辆
- 本人姓名+身份证号，入校刷**身份证原件**。
- 车：前往东校区的轿车**从黄山路北门驶入**，停老北门外停车场或划线车位；校内限速 20 km/h 禁鸣笛。普通游客车辆能否随人入校未核实。
- 各渠道均免费。

## 二、进了校之后怎么逛（以东区为主）

### 2.1 交通与校门
- 东区北门（黄山路，车辆口）、**东区老北门（金寨路侧，最有历史感）**、东区西门。
- 地铁 5 号线"中国科大东区站"可达东区北门附近（出口对应关系未官方核实）。

### 2.2 点位明细
| 点位 | 看点 | 开放情况 |
|---|---|---|
| 东区老北门 | 现存最老校门，郭沫若题校名，旁有 50 年紫藤 | — |
| **郭沫若广场** | 首任校长铜像，"红专并进"箴言，返校打卡核心 | 开放 |
| 樱花大道（东区） | 约 200 米晚樱长廊，3–4 月热门 | 户外 |
| 眼镜湖·一鉴亭 | 取朱熹"半亩方塘一鉴开" | 户外 |
| **校史馆（东区）** | 校史+"两弹一星"科学家精神展 | 周一三五 14:00–17:30、周六日 9:30–17:30，17:00 停入；团队讲解 0551-63607293 |
| 中科大博物馆（东区） | | **周二–日 9:30–17:30 免费，周一闭馆** |
| 西区也西湖 | 核心景观湖，黑天鹅"团宠" | 户外 |
| 国家同步辐射实验室（西区） | 大科学装置 | **仅科技活动周等特定活动开放** |

### 2.3 推荐动线
- **半天（东区）**：老北门 → 郭沫若广场 → 樱花大道 → 眼镜湖一鉴亭 → 校史馆/博物馆。
- **一天**：上午东区同上 → 中午西区 → 下午也西湖（黑天鹅）→ 西区林荫道 → 严济慈铜像。

## 四、注意事项
- 勿进教学区、实验室；部分科研区域禁拍照（以现场标识为准）；少年班学院谢绝参观；樱花季往年曾"云赏樱"，说明非活动日管理较严——**别按"别的学校都能逛"的预期来科大**。
