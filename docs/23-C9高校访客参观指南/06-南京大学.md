# 23-06 · 南京大学（鼓楼校区为主，另有仙林校区）

> 调研日期 2026-11-04。信源：南大官微"访客入校"指引（澎湃转发，2025 春季学期）、腾讯新闻/南京本地宝 2025-11、校史博物馆官网 historymuseum.nju.edu.cn（含 2025-12-02 拉贝纪念馆重开公告）、现代快报 2025-12-13。**出行前以南大公众号当日信息为准。**

---

## 一、入校预约（个人）

### 1.1 渠道与规则
- 统一入口：微信公众号"**南京大学**"菜单"**访客入校**"，分两类：
  | 类型 | 适用 | 说明 |
  |---|---|---|
  | **访客通行** | 工作日办事 | **需校内联系人**（填审核人单位+姓名），审核通过凭二维码进 |
  | **开放日预约** | **双休日+法定节假日**参观 | 鼓楼、仙林、浦口、苏州四校区开放，**无需校内联系人** |
- 开放日规则：**可约当天或未来 7 日；每天上午 9:00 放新号；每位自然人半年内每校区仅可约 1 次**；时段 **8:00–12:00、14:00–17:00**；当天 12 点前可取消；凭**二维码**进校（仅当天显示）。
- 儿童也需实名预约（一人一约）。

### 1.2 团体
- 生源中学师生走专门小程序"南京大学生源中学团队预约"，需**中学介绍信**。其他团体对接流程未核实，咨询电话 **025-89683791**（8:00–19:00）。

### 1.3 证件、车辆、收费
- 开放日凭二维码进校；能否刷身份证原件入闸待核实。
- 车辆：官方建议公共交通。办事通行可在预约时填随行车牌（仙林校区审批后自动抬杆）；**开放日参观原则上车辆不入校**。
- **免费**；勿信有偿预约。

## 二、进校之后怎么逛

### 2.1 交通
- **鼓楼校区（北园）**：汉口路正门进。地铁 1/4 号线**鼓楼站**或 1 号线**珠江路站**，步行 500–700 米。
- **仙林校区**：仙林大道正门。地铁 2 号线**南大仙林校区站**。

### 2.4 推荐动线
- **鼓楼半天**：汉口路门 → 校史馆 → 二源壁 → 大礼堂 → 北大楼 → 烈士碑/大纛坪 → 赛珍珠纪念馆 → 斗鸡闸 → 出校步行至拉贝纪念馆。
- **仙林半天**：南门 → 二源广场/杜厦图书馆外观 → 藜照湖 → 星云楼 → 敬文活动中心 → 香雪海。
- **一天**：上午鼓楼（8:00–12:00 场），中午汉口路/陶谷新村觅食；下午地铁 1 号线转 2 号线约 30–40 分钟至仙林（14:00–17:00 场）。

## 三、吃饭
- 食堂以校园卡支付为主；"少量窗口可现金/扫码"仅见攻略、非官方口径，**未核实**。稳妥：出校在汉口路、青岛路、陶谷新村就餐（餐饮密集），或门口问安保。

## 四、注意事项
- 教学楼、图书馆内部、宿舍区不开放；上午 9–11 点、下午 3–5 点光线最佳；遇重大活动/极端天气暂停开放。
