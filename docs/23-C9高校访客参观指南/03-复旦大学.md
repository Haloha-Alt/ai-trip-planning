# 23-03 · 复旦大学（邯郸校区为主，杨浦区邯郸路 220 号）

> 调研日期 2026-11-04。信源：复旦保卫处《关于新学期优化校园开放措施的通告》（2024-08-31 发布、2024-09-02 施行，复旦信息公开网）、"复旦信息办"公众号登记指引、复旦文明网《"复旦源"文化育人功能区启幕》2025-05、杨浦区政府 2025-12-04。**出行前以"复旦信息办"当日信息为准。**

---

## 一、入校登记（个人）——C9 头部校里最宽松的一档

### 1.1 渠道与规则
- **「复旦信息办」微信公众号 →"进校服务"→"社会公众进校登记"**，**提前 1 天**登记（当日 00:00 放次日名额），选"上午"或"下午"。
- 登记时段：上午票 6:00–11:00 进；下午票 13:00–22:00 进；校区整体开放 6:00–22:00。
- 单个微信号当日限登记 1 次、7 日内最多 2 次；**无需校内人员邀请**；工作日周末均登记制，无抽签。
- 凭证：所选时段内刷**身份证原件或随申码**进校。

### 1.2 分校区差异（重要）
| 校区 | 怎么进 |
|---|---|
| **邯郸校区本部**（含北苑学生生活园区） | 须登记后进校 |
| 邯郸校区其他区域 | **免登记**刷身份证进 |
| 枫林 / 江湾 / 张江校区 | **免登记**刷身份证进 |

### 1.3 车辆与收费
- **不支持访客机动车进校**；确因工作需要须由校内单位走 eHall 申报（= 必须有校内对接人）。
- 免费。未成年人须由监护人陪同。

### 1.4 「复旦源」专题预约（强推，含校史馆+博物馆等六馆）
- **"复旦源"微信小程序**，提前 7 日（不含当日）预约；分时段 9:00–12:00 / 12:00–14:30 / 14:30–17:00；同一手机号 7 天内最多约 2 天。
- **预约成功后凭身份证直接进校，无需再抢入校登记名额**（这条含金量很高——等于多了一条免登记入校路径）。
- 开馆：**周二至周日 9:00–17:00，周一及法定节假日闭馆**；博物馆 16:00 停止入馆，艺术馆/科技成果馆 16:30 停止入馆。
- 校史馆另要求至少提前 1 天预约，电话 021-65646237；特藏档案馆无需预约；校友馆仅对校友开放。
- 校友：刷电子校友卡进校，食堂就餐收 20% 搭伙费。

## 二、进校之后怎么逛

### 2.1 交通
- 邯郸校区正门：地铁 18 号线**复旦大学站 2 号口**，左转沿邯郸路向东约 400 米；离校走 1 号口（官方推荐）。
- 江湾校区：10 号线国帆路站 3 号口直达 2 号门；枫林校区：7/9 号线肇嘉浜路站。
- 官方推荐进校门：正门 / 南三门 / 老校门。

### 2.2 推荐动线
- **半天（3 小时）**：正门 → 老校门 → **复旦源六馆**（重点校史馆 + 博物馆，约 2 小时）→ 相辉堂草坪 → 子彬院 → 18 号线复旦大学站 1 号口出。**避开周一。**
- **一天**：上午六馆；中午南区/南苑食堂；下午光华大道（600 米梧桐道）→ 光华楼双子塔 → 曦园 → 燕园 → 玖园建筑群外观（陈望道、苏步青旧居）→ 寒冰馆。

### 2.3 点位明细
| 点位 | 看点 | 开放情况 |
|---|---|---|
| 老校门 | 四柱三门木构庑殿顶，魏体"复旦大学"匾 | 外观 |
| 复旦源文化区 | "一源六馆"，第八批中国 20 世纪建筑遗产 | 小程序预约 |
| 校史馆 | 存世最早复旦文凭、题写校名手迹 | 周二–日 9–17，提前1天约 |
| 博物馆（相伯/简公/景莱堂） | 《多元一体：中华文明溯源展》等 | 同上，16:00 停入 |
| 艺术馆 | "日月复光华"首展 | 同上 |
| 科技成果馆 | 芯片/AI/生命健康成果 | 同上 |
| 特藏档案馆 | 百余年手稿档案 | 无需预约 |
| 相辉堂 | 1922 年礼堂，纪念马相伯、李登辉 | 外观 |

| 光华楼 | 双子塔现代地标 | 外观 |

| 玖园建筑群 | 陈望道、苏步青旧居 | 外观（开放与否待核实） |

### 2.4 官方推荐路线
正门/南三门/老校门进 → 望道路 → 博学南路向西 → 复旦源核心区六馆 → 18 号线 1 号口离校。

## 三、吃饭
- 邯郸校区仅**南区食堂、南苑食堂**对公众开放（微信/支付宝支付，2026-05 开放日确认）；江湾/枫林/张江校区食堂保持对外开放。
- 避开 11:15–12:30；谢绝借校园卡。

## 四、注意事项
- 不进教学科研办公场所及宿舍；**未经学校审批不得对教学/工作/生活内容拍照、摄像、直播**；禁宠物、禁搭帐篷露营野餐放风筝；无人机须"随申办"报备+保卫处批准。
- 周末 9:00–11:00、15:00–17:00 有校园导览志愿服展（叶耀珍楼出发，以实际安排为准）。

## 五、待核实（出发前确认）
1. 邯郸本部登记是否设每日人数上限
2. 六馆是否需各自约场次、特展是否收费
3. 南区/南苑食堂对访客窗口细节
4. 玖园修缮后是否开放
5. 团体通道（10 人以上）
6. 邯郸路以南"免登记区域"的准确边界
