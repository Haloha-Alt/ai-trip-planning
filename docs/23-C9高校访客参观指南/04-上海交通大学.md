# 23-04 · 上海交通大学（闵行校区为主，另有徐汇校区）

> 调研日期 2026-11-04。信源：《上海交通大学校园访客参观管理暂行办法》（沪交校园〔2025〕5号，2025-06-28 印发，信息公开网 gk.sjtu.edu.cn）、上海发布 2025-03、今日闵行官方号 2025-04、上观新闻 2025-07、校史博物馆官网 museum.sjtu.edu.cn。**出行前以"上海交通大学"公众号当日信息为准。**

## 一、入校登记（个人）——当天登记当天进，最省事

### 1.1 渠道与规则
- **"上海交通大学"官方公众号 → 菜单"参观交大"→"临时访客入校信息登记系统"**，**按校区分别登记**：
  - 闵行校区：https://sjtu.cn/vreg/mh
  - 徐汇校区：https://sjtu.cn/vreg/xh
  - 七宝校区：https://sjtu.cn/vreg/qb
- **个人登记仅限当天有效**（保卫处热线 54741234 于 2025-04、2025-06 两次确认）——当天登记当天进，不能提前约。
- 凭**身份证原件或随申码**过闸机。
- **免费**；官方提醒防范有偿代约黑产。

### 1.2 团体（≥10 人且同一单位）
- 依《暂行办法》由校园管理办公室登记；**团体参观开放时间为双休日、法定节假日及寒暑假**，寒暑假期间周一为休整日。
- 具体提前天数与流程未完全核实，建议致电保卫处。

### 1.3 车辆（C9 里少见的宽松）
- **社会小轿车可入校、无需提前报备**，按标准收费：闵行校区 **6 元/小时**（保卫处 2025-06 答复）。徐汇校区标准未核实。
- 文博场馆周一闭馆（见下），校园本身个人登记未见"周一不开放"表述，待核实。

## 二、进校之后怎么逛（闵行校区）

### 2.1 交通
- 地铁 5 号线**东川路站**步行约 10 分钟到东大门；南门"思源门"（东川路 600 号）为社会车辆入口。
- 校区近 5000 亩，**进校后骑共享单车或乘免费校园观光巴士**（官方研学线路推荐）。

### 2.2 推荐动线（官方研学线路整理）
- **半天**：思源门 → 纪念品中心 → 撷英园 → 思源湖 → 程及美术馆 → 包玉刚图书馆（外观）→ 玉兰苑午餐 → 文博楼校史博物馆 → 东大门（紫气东来门）收尾。
- **一天**：上午前半段 + 园林植物标本园；下午蔷薇园 → 鹿苑（**仅周一至周五、周日 10:00–12:00 / 14:00–16:00 开放**）→ 致远湖 → 文博楼（**周二至周日 10:00、14:30 有定时讲解**）→ 东大门。

### 2.4 徐汇校区（半天即可，与闵行二选一或顺路）
- 入口：华山路 1954 号**一号门（"庙门"，1935 年仿古官式大门）**；地铁 10 号线交通大学站 / 1·9·11 号线徐家汇站。
- 官方新生"继往开来线"：老图书馆 → 新中院（**董浩云航运博物馆**，周二–日 9–17，周一闭馆）→ 中院（1899 年建，现存最老教学楼）→ 新上院 → 工程馆 → 容闳堂 → 体育馆 → 红太阳广场 → 华山路校门。
- 校外顺游：**钱学森图书馆**（华山路 1800 号，免费，周二–日 9–17（16:30 停入），"钱学森图书馆"公众号预约）。

## 三、吃饭
- 《暂行办法》第六条写"未经允许不得进入学生食堂"，但访客面信息显示**玉兰苑对校外人员开放**：10:00–22:00，**微信支付**，无需校园卡（1F 统禾餐饮、2F 一等茶餐厅 10:30–21:30）。其余食堂是否开放未核实。
- 两处口径有张力：**去玉兰苑没问题，别的食堂别硬闯**。

## 四、注意事项
- 不得擅入办公楼、教学楼、实验室、图书馆、体育馆、宿舍及学生食堂（办法第六条）；按指定路线参观；禁黑导游商（办法第七条）。
