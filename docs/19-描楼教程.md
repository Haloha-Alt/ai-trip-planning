# 19 · 描楼教程：20 分钟把卫星图变成"自己的校园图"

> 版本 v1.0 ／ 2026-11-03 ／ 目标：做完你有一张**楼栋级**的校园图，不依赖学校授权。
> 工具：`design/draw-buildings.html`（零依赖，需要本地 http 才能开）。

---

## 一、先明白在做什么

高德卫星图能看清屋顶，但**不知道哪栋楼叫什么**。你要做的是：**沿着屋顶描一圈，给它起名字**。
描完存成 geojson，页面就能按 `poi_id` 把行程里的站点高亮出来——这是校方瓦片都做不到的（它是死图片）。

一栋楼 = 一个多边形（6–10 个点就够，不用很精细）。

## 三、逐栋操作（每栋 15–40 秒）

| 步 | 动作 | 说明 |
|---|---|---|
| 1 | 滚轮放大到 **18 级** | 能看清屋顶边缘、连廊、台阶 |
| 2 | 左侧「这栋楼叫」下拉选名字 | 18 个常用楼已在里面；没有就在下面输入框手填（如"文印中心"） |
| 3 | 选「用途分类」 | 决定颜色：蓝=教学楼/图书馆、红=食堂、褐=宿舍、绿=体育馆、橙=生活服务 |
| 4 | 在屋顶**边缘**依次点 5–8 个点 | 顺时针或逆时针都行，别交叉 |
| 5 | 双击闭合 | 松开鼠标会看到浅红色填充 |
| 6 | 点「保存这栋」 | 左侧列表会多一行 |

**点歪了**：按「撤销一点」退一个点；整栋废了就按「放弃这栋」。

## 五、导出与落地（描完 12 栋再做）

1. 点「导出 geojson」→ 得到 `buildings.geojson`；
2. **浏览器默认存到"下载"目录**，把它移动过去：

```powershell
move "$env:USERPROFILE\Downloads\buildings.geojson" "D:\projects\ai-trip-planner\data\cities\dalian\buildings.geojson"
```

3. 让页面用上它（这一步需要改前端，可以交给我做，改动约 30 行）：

```js
// 伪代码：拿到 plan 后
fetch('/buildings.geojson').then(r => r.json()).then(fc => {
  const onTrip = new Set(plan.days.flatMap(d => d.items.map(i => i.poi_id)));
  fc.features.forEach(f => {
    const hit = onTrip.has(f.properties.poi_id);
    new AMap.Polygon({
      path: f.geometry.coordinates[0].map(([lon, lat]) => [lon, lat]),
      strokeColor: hit ? '#b23a2f' : '#8f8878',
      strokeWeight: hit ? 2 : 1,
      fillColor: hit ? '#b23a2f' : '#8f8878',
      fillOpacity: hit ? 0.28 : 0.08,   // ← 行程里的楼亮，其余楼灰
    }).setMap(map);
  });
});
```

## 六、验收标准

| 判据 | 门槛 |
|---|---|
| 描好的楼 | ≥ 12 栋（覆盖上面那张表） |
| 每栋顶点数 | 4–12 个（少于 4 不合规，多于 15 说明你在抠细节，没必要） |
| geojson 合法性 | `json.load()` 能读、`features` ≥ 12、每条 `coordinates[0]` 首尾闭合 |
| 目视 | 放大到 18 级，轮廓贴着屋顶，没有把马路框进去 |
| 文件大小 | < 60 KB（12 栋 × 8 点 ≈ 8 KB，别担心） |

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点一下没反应，或轮廓乱跳 | 你在地图**拖动**时触发了 click。改用单击、不要拖 |
| 双击后没有填充 | 少于 3 个点。至少 3 个才成面，建议 5 个以上 |
| 楼名下拉里没我要的楼 | 下面输入框直接手填，`poi_id` 留空也行（只是没法按行程高亮） |
| 关掉网页后描的都没了 | **正常**。geojson 只在内存里，请先「导出」再关；建议每描 5 栋导出一次 |
| 卫星图打不开 / 一片灰 | Key 白名单或网络。检查 `.env` 的 `AMAP_JS_KEY`，或换手机热点 |
| 描完发现楼歪了 | 重新描那栋，再导出覆盖即可（文件是整体覆盖，不是增量） |

## 八、描完之后，这张图能干什么

| 用途 | 效果 |
|---|---|
| 行程高亮 | 行程里的楼亮红、其余灰，一眼看出"今天去哪几栋" |
| 时间轴联动 | 点轴上的站 → 对应楼闪烁（比 pin 点更有说服力） |
| 离线可用 | geojson 是本地文件，断网照样画（高德瓦片不行） |
| 答辩说法 | "这张校园图是我们自己描的——**不是学校的，也不是高德的**" |

> 这一句的分量，比"我们申请到了学校授权"更硬：
> 授权是别人的东西你能用；描图是你自己的东西。
