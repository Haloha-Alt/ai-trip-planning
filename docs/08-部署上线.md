# 08 · 部署上线（域名 / 服务器 / HTTPS）

> 面向目标：**一个固定域名，任何人任何网络都能打开，并且能正常调用大模型**。
> 如果只是临时给几个人看，`docs/06-内网穿透与分享.md` 更快，不用买任何东西。

---

## 零、先做这一步，否则后面全白费

**大模型网关可能只对校园网放行。** 云服务器的出口 IP 在校外，
如果网关不放行，网站能打开、但一生成解说就退回规则 —— 看着能用，其实是坏的。

拿到服务器后**第一件事**不是装 Python，而是：

```bash
curl -sS -m 10 -o /dev/null -w "%{http_code}\n" \
  http://aigw.dlut.edu.cn/v1/models -H "Authorization: Bearer 你的Key"
```

| 返回 | 含义 | 怎么办 |
|---|---|---|
| `200` | 通 | 继续 |
| `401` | 网络通、Key 不对 | 换 Key 再试 |
| `403` / 超时 | **被来源 IP 拦了** | 别上公网了，回到"本机 + 内网穿透" |

这个判断决定你后面买不买服务器。**先测，再花钱。**

---

## 一、三种上线方式，怎么选

| 方式 | 固定域名 | 成本 | 备案 | 适合 |
|---|---|---|---|---|
| **A 本机 + 内网穿透** | ❌ 免费版域名会变 | 0 元 | 不需要 | 答辩、临时分享 |
| **B 云服务器 + Docker** | ✅ | ~10–60 元/月 | **要** | 长期给别人用 |
| **C 云服务器 + systemd** | ✅ | 同上 | **要** | 同上，但不用装 Docker |

> 服务器在中国大陆 → **必须 ICP 备案**才能用 80/443 绑域名，周期 7–20 天。
> 想跳过备案只能用中国香港/海外服务器，延迟和合规另说。

## 二、阿里云操作顺序（照这个顺序，少跑冤枉路）

1. **买域名**：域名注册 → `.com` 首年约 55–70 元。买完立刻做**实名认证**（1–2 个工作日），
   不实名域名会被 hold，后面备案也过不去
2. **高校认证**：搜「阿里云高校计划」/「云翼计划」，用学信网或学生证认证。
   ⚠️ 折扣主要在 **ECS**，域名基本不打折 —— 别为了折扣去凑单
3. **买 ECS**：地域选离你近的（华北 2 张家口/北京），1 核 2G、40G 系统盘足够。
   镜像选 **Ubuntu 22.04**
4. **ICP 备案**：阿里云 App → ICP 备案 → 个人性质。**这步最慢，先提交再干别的**
5. **安全组放行**：ECS 控制台 → 安全组 → 入方向 → 放行 `80`、`443`、`22`。
   ⚠️ 只放行 22 会让你网站打不开，这是最常见的"部署完了访问不了"
6. **域名解析**：域名控制台 → 解析 → 添加 A 记录，主机记录 `@`，值填 ECS 公网 IP；
   再来一条 `www` 指向同一 IP

## 三、把代码放上服务器

```bash
# 本地：推上去（记得先把 .env 排除，它已经在 .gitignore 里）
git push origin main

# 服务器：
sudo apt update && sudo apt install -y git python3.12 python3.12-venv nginx
sudo mkdir -p /opt && cd /opt
sudo git clone https://github.com/你的用户名/ai-trip-planner.git
cd ai-trip-planner

# 造 .env（**只在服务器上写 Key，不要提交**）
cp .env.example .env
nano .env        # 填 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL / ACCESS_CODE
```

**上线前自检**（这一步别跳，它会把坑一次性列出来）：

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-server.txt
.venv/bin/python -m tools.preflight --with-tests
```

`preflight` 会逐项告诉你：网关通不通、口令设没设、数据全不全、测试绿不绿，每项都带"下一步做什么"。

## 四、让它常驻（二选一）

### 方式 B：Docker（推荐，环境干净）

```bash
sudo apt install -y docker.io docker-compose-v2
sudo docker compose up -d --build
sudo docker compose ps          # 看 STATUS 是否 healthy
sudo docker compose logs -f     # 出问题看这里
```

仓库里已经准备好 `Dockerfile` / `docker-compose.yml` / `.dockerignore`：
镜像只装 `uvicorn + starlette`（引擎是纯标准库），**不装 streamlit 那一套**，体积小、启动快。

### 方式 C：systemd（不装 Docker）

```bash
sudo cp deploy/trip.service /etc/systemd/system/ai-trip.service
sudo nano /etc/systemd/system/ai-trip.service   # 改 User / WorkingDirectory / 路径
sudo systemctl daemon-reload
sudo systemctl enable --now ai-trip
sudo systemctl status ai-trip
journalctl -u ai-trip -f                        # 看日志
```

> 为什么不用 `nohup python -m api.server &`：SSH 一断进程就没了，服务器重启也不自启。
> systemd 会挂掉自动拉起、开机自启、日志统一进 journal。

## 五、Nginx + HTTPS

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/ai-trip
sudo nano /etc/nginx/sites-available/ai-trip     # 改 server_name 和证书路径
sudo ln -s /etc/nginx/sites-available/ai-trip /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

**证书**两条路，任选：

- 阿里云控制台申请**免费 DV 证书**（一年一换，下载 Nginx 格式两个文件）
- 或在服务器上：`sudo apt install certbot python3-certbot-nginx`，然后
  `sudo certbot --nginx -d 你的域名.com`（自动续期）

配置里有两个点是为本项目专门调的，别改回去：

- `proxy_read_timeout 120s` —— 大模型写整段解说可能要几十秒，默认 60s 会掐断
- 容器/服务只监听 `127.0.0.1`，对外一律走 Nginx（HTTPS 与口令都在这一层收口）

## 六、安全（开放到公网前必看）

| 要做 | 为什么 |
|---|---|
| `.env` 里设 `ACCESS_CODE` | 没有口令 = 任何人拿到域名都能烧学校额度 |
| `WEB_HOST=127.0.0.1` | 服务只听本机，外界只能经 Nginx 进来 |
| `.env` 不进 git、不进镜像 | `.gitignore` 与 `.dockerignore` 都已排除，别手动 `-f` 覆盖 |
| 定期看用量 | `/api/llm` 有最近调用记录，异常增长说明有人在用 |

## 七、上线后验收（5 条，一条都别省）

```bash
# 1) 服务活着（设了口令也会返回 401，那是正常的，脚本已处理）
.venv/bin/python deploy/healthcheck.py

# 2) 域名解析对了
curl -I https://你的域名.com

# 3) 带口令能出数据
curl -s "https://你的域名.com/api/health?code=你的口令"

# 4) 大模型真的能调（最关键，很多"部署成功"挂在这）
curl -s "https://你的域名.com/api/plan?code=你的口令" \
  -H "Content-Type: application/json" \
  -d '{"query":"下午自习然后吃饭","scenario":"daily","strategy":"stub","narrate":true}'
# 看返回里 warnings 有没有 "[narrate]" —— 有就说明模型没调通，只是界面能用

# 5) 换了网络也能开（用手机流量试一次）
```

## 八、常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 域名打不开，IP 能开 | 解析没生效 / 备案没过 | `dig 你的域名` 看 A 记录；备案没过 80/443 会被拦 |
| 502 Bad Gateway | 后端没起 / 端口不对 | `docker compose ps` 或 `systemctl status` |
| 页面能开、点生成报错 | 口令没过 | 用带 `?code=` 的完整链接 |
| 生成很慢然后退回规则 | 大模型超时 | 网关慢或不通，看第零节 |
| HTTPS 证书警告 | 证书域名不匹配 | `server_name` 与证书域名要一致 |
| 重启后网站没了 | 用了 nohup | 换 systemd 或 Docker（`restart: unless-stopped`） |

---

## 九、一句话总结

**先测网关，再买服务器；备案先行，Nginx 收口，systemd 兜住常驻，preflight 收尾。**
