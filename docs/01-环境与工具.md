## 一、从零开始要装什么

### 1.1 三件套

| 软件 | 版本要求 | 怎么验 |
|---|---|---|
| Python | **≥ 3.11**（用到标准库 `tomllib`）；本项目开发用 3.14.6 | `python --version` |
| PyCharm | Community 或 Professional 都行（差别见 3.5） | 帮助 → 关于 |
| Git | 2.4x 以上；建议同时装 GitHub Desktop | `git --version` |

### 1.2 安装 Python 时的那个勾

安装界面底部有 `Add python.exe to PATH`。**勾上**。不勾的后果是终端里敲 `python` 提示找不到命令。
已经装错也没关系：不用重装，直接用完整路径 `D:\python\python.exe`（本项目所有命令都写完整路径，就是为了绕开这个问题）。

### 1.3 验证环境（30 秒）

```bat
cd /d D:\projects\ai-trip-planner
.venv\Scripts\python.exe -c "import sys,streamlit;print(sys.version.split()[0], streamlit.__version__)"
.venv\Scripts\python.exe -m unittest discover -s tests -t .
```

期望输出：`3.14.6 1.66.1`，紧接着 `Ran 68 tests ... OK`。
（你的版本号可能不同，**只要不报错就算通过**。版本号不同不代表装错了 —— 见 6.2。）

> 2026-10-28 起本项目**不再依赖 pandas**（数据层改用标准库 `csv`），所以这里不再检查它。
> 原因：pandas 的 `timezones.pyd` 会被 Windows「应用程序控制策略」拦截，报
> `ImportError: DLL load failed while importing timezones`，换一台机器就可能直接跑不起来。

## 二、项目与虚拟环境

### 2.1 队友 clone 之后的第一件事

**`.venv` 不在版本库里**（`.gitignore` 把它排除了，否则仓库会大几百 MB）。所以 clone 下来**必须自己建一次**：

```bat
git clone https://github.com/Haloha-Alt/ai-trip-planning.git D:\projects\ai-trip-planner
cd /d D:\projects\ai-trip-planner
D:\python\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

如果 pip 下载慢，换清华源（只影响你自己这台机器）：

```bat
.venv\Scripts\python.exe -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2.2 `.venv` 被误删了怎么恢复

```bat
D:\python\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```
然后在 PyCharm 里重新指一次解释器（见 2.3）。**不用重装 Python。**

### 2.3 三处必须指向同一个解释器

最容易出的问题：终端里装好了库，PyCharm 里还是报 `ModuleNotFoundError`。

| 位置 | 怎么确认 |
|---|---|
| PyCharm 解释器 | `Ctrl+Alt+S` → Project → Python Interpreter → 路径应为 `D:\projects\ai-trip-planner\.venv\Scripts\python.exe` |
| PyCharm 终端 | 底部 Terminal 里敲 `python -c "import sys;print(sys.executable)"`，路径应与上面一致 |
| 运行配置 | `Run → Edit Configurations → Interpreter` 应显示同一路径 |

三处不一致 → 一律改成同一个。

### 2.4 装依赖的三种方式

| 方式 | 操作 | 什么时候用 |
|---|---|---|
| **A 图形界面**（推荐） | `Ctrl+Alt+S` → Python Interpreter → 点 `+` → 搜包名 → Install Package | 临时装一个包 |
| **B requirements.txt** | `.venv\Scripts\python.exe -m pip install -r requirements.txt` | 换机器、重建环境 |
| **C 离线 wheel** | 下载 `.whl` 到本地 → `pip install D:\path\xxx.whl` | 完全没网 |

> ⚠️ **不要在 PyCharm 终端里裸敲 `pip install`**。它可能装到别的 Python 上，然后 PyCharm 里依然报错。要用终端就写 `.venv\Scripts\python.exe -m pip install 包名`。

### 2.5 本项目的依赖现状

当前依赖（2026-10-28 起**不含 pandas**）：

```
streamlit==1.66.1  numpy  requests  python-dotenv
altair  pyarrow  pydeck  uvicorn  watchdog
```

其中**只有 streamlit 是必需的**：引擎、数据层、CLI、测试全部只依赖标准库。
也就是说 —— 就算 `pip install` 全失败，只要能装上一个 streamlit，项目就能跑；
再不济还能只用命令行（`main.py`）完整演示一遍。

**骨架阶段一个新包都不用装。** 特别是不装：`pytest`（用标准库 unittest）、`plotly`、`folium`、`pydantic`。

## 三、PyCharm 操作手册（补 `使用手册.md` 的空白）

### 3.1 运行配置详解

**跑 `main.py`**：左侧文件右键 → `Run 'main'`。要带参数就 `Run → Edit Configurations` → 在 `Parameters` 里填，例如：

```
--scenario demo --strategy stub --top-n 3
```

**跑 Streamlit（必须单独建配置）**：

| 字段 | 填什么 |
|---|---|
| 类型 | Python |
| Module name | `streamlit`（注意：不是 Script path） |
| Parameters | `run ui/app.py` |
| Working directory | `D:\projects\ai-trip-planner` |

保存后点绿三角启动。**不要**对 `ui/app.py` 直接点绿三角 —— 页面不会出来。

**跑测试**：左侧 `tests` 目录右键 → `Run 'Unittests in tests'`。

**设环境变量**（例如换默认场景）：Edit Configurations → `Environment variables` 填 `TRIP_SCENARIO=campus`。

### 3.2 断点调试（用真实 bug 当教材）

**什么时候值得用**：`print()` 看不出问题时。比如"侧边栏把预算抹成了 None"这类，靠 print 只能看到结果，看不到是哪一行覆盖的。

**操作**：

1. 在 `ui/app.py` 的 `req.daily_budget = ...` 那一行左侧灰边**点一下**，出现红点 = 打了断点
2. 点**虫子图标**（Debug）而不是绿三角
3. 程序停在断点处，界面变成：
   - **Variables** 窗（右侧）：看当前所有变量的值
   - **Watches** 窗：手动加表达式，比如 `req.daily_budget`
   - **Console** 窗（底部）：可以敲 `req.daily_budget` 当场求值
4. 步进按钮：
   | 按钮 | 快捷键 | 作用 |
   |---|---|---|
   | Step Over | `F8` | 执行这一行，进入下一行（不钻进函数） |
   | Step Into | `F7` | 钻进被调用的函数 |
   | Step Out | `Shift+F8` | 跳出当前函数 |
   | Resume | `F9` | 继续跑到下一个断点 |

**条件断点**：右键红点 → 填 `req.daily_budget is None`，只有条件成立才停。查"什么情况下预算丢了"特别有用。

> ⚠️ **Streamlit 应用不能用 Debug 启动**（它是另起进程跑的）。替代方案：把 `ui/app.py` 里的逻辑临时抽成一个小函数，用 `main.py` 传同样的参数跑，在 `engine/planner.py` 里打断点。或者退一步用 `print` + 命令行。

**Evaluate Expression（`Alt+F8`）**：不打断点也能当场算表达式，看 `cfg.weights`、`resp.metrics` 的值。

### 3.3 端口被占用 / 关不掉服务

**端口 8501 被占**（常见于上次没关干净）：

```bat
.venv\Scripts\python.exe -m streamlit run ui/app.py --server.port 8502
```

或者找出来杀掉：

```bat
netstat -ano | findstr :8501
taskkill /PID <上面查到的PID> /F
```

**关服务**：PyCharm 终端里 `Ctrl+C`。关不掉就点终端右上角的红色停止按钮，或者直接关掉那个 Terminal 标签页。

### 3.4 改错了怎么救

| 场景 | 用哪个 |
|---|---|
| 刚改完还没提交，想反悔 | PyCharm 右键文件 → `Local History → Show History`，能看到每次保存的快照，右键某条 → `Revert` |
| 已经提交了，想退回 | `git restore .`（丢工作区）/ `git revert <sha>`（生成反向提交，安全） |
| 整个文件想回到上一次提交的版本 | 右键文件 → `Git → Rollback` |

**Local History 是本项目最被低估的功能**：它不受 git 影响，PyCharm 每隔一会儿自动存一份，即使你没提交也能找回。

### 3.5 两个人同时看代码

| 方案 | 前提 | 怎么做 |
|---|---|---|
| **Code With Me** | 需要 PyCharm **Professional**（Community 没有） | 右上角头像 → Code With Me → 生成链接 → 发给队友 → 他点链接进浏览器就能跟你同屏看/改 |
| **屏幕共享 + 轮流驾驶**（Community 可用） | 腾讯会议/飞书都行 | 一人共享屏幕讲解，另一人只看不敲；换人时明确说"现在换你" |

> 建议：**别两个人同时改同一个文件**。即使有 Code With Me，也按 `分工与所有权.md` 的 ★ 规则来。

### 3.6 运行配置为什么共享不了

`Ctrl+Alt+S` 里配好的 Streamlit 运行配置，存在 `.idea/workspace.xml` 里，而 `.idea/` 被 `.gitignore` 排除了 —— 所以**队友 clone 后必须自己再配一次**。

三种应对：

1. **推荐**：把配置写进文档（就是本节 3.1 那张表），每人照着手建一次，30 秒的事
2. 进阶：把 `.idea/runConfigurations/*.xml` 单独纳入版本控制（需要改 `.gitignore`，属于可选优化，新手别碰）
3. 偷懒：每人自己建，不共享

## 四、插件清单

装插件路径：`Ctrl+Alt+S` → Plugins → 搜名字 → Install → **重启 PyCharm**。

### 4.1 必装三件

| 插件 | 作用 | 装完你会看到什么变化 |
|---|---|---|
| **Black**（BlackConnect） | 一键格式化，全项目风格统一 | 右键菜单多出 `Reformat with Black`；`Ctrl+Alt+L` 也能用 |
| **GitToolBox** | 在当前行末尾显示"这行是谁什么时候改的" | 代码行右侧出现灰色小字 `Haloha-Alt, 2 days ago` |
| **Rainbow CSV** | CSV 每列不同颜色 + 显示列名 | 打开 `data/pois.csv` 时每列颜色不同，底部显示列号 |

### 4.2 选装

| 插件 | 值不值得 | 说明 |
|---|---|---|
| **CSV Editor** | 值得 | 表格形式编辑 CSV，比看逗号舒服得多。改完记得**另存为 UTF-8** |
| **Markdown**（内置） | 已内置 | 预览 `docs/*.md`：右上角分屏图标 |
| **TOML** | 值得 | `config/scenarios/*.toml` 语法高亮，写错会标红 |
| **Key Promoter X** | 新手值得 | 你用鼠标点了某个按钮，它弹提示告诉你快捷键是什么 |
| **Ruff** | 可选 | 静态检查，能提前发现未使用变量、拼写错误的函数名 |

### 4.3 Ruff 和 Black 会打架（重要）

两个都能格式化，同时开就会互相改。**规则：Black 负责格式化，Ruff 只开 lint。**

Ruff 设置里把 `ruff.format` 关掉，只留 `ruff.lint`。否则你会发现"格式化完又变回去了"。

### 4.4 格式化必须统一行宽

`Ctrl+Alt+S` → Tools → Black → Line length 填 **100**（默认 88 也行，但两个人必须一样）。

不统一的后果：第一次格式化会产生几百行纯格式 diff，把真正的改动埋掉，`git diff` 完全没法看。

### 4.5 不建议装

| 类型 | 为什么 |
|---|---|
| AI 代码补全类（Copilot 等） | 会绕过 `02` 的提示词流程，改出你讲不清的代码；答辩被问"这行为什么这么写"会答不上 |
| Docker / 数据库类 | 本项目用不到，白占内存 |
| 各种主题美化 | 与 `Ctrl+Alt+S` 的路径对不上，照着文档找不到设置项 |

### 4.6 装完自检

1. 打开 `ui/render.py`，右键 → `Reformat with Black`
2. 看 `git diff ui/render.py`：**只应该有 0~2 行变化**（说明代码本来就已经符合 Black 风格）
3. 如果 diff 有几十行 → 说明 line length 设错了，改回 100 再试

## 五、命令行环境

### 5.1 为什么每条命令都写完整路径

```bat
.venv\Scripts\python.exe main.py          ← 一定是对的
python main.py                            ← 可能指向 D:\python\python.exe（另一套环境）
```

因为 Windows 上 `python` 到底指向哪个解释器，取决于 PATH 和历史安装，**光看命令看不出来**。写完整路径就永远不会错。

### 5.2 三种终端的差异

| 终端 | 注意 |
|---|---|
| **PyCharm Terminal**（推荐） | 自动在项目根目录，最省事 |
| **PowerShell** | 不支持 `&&`，要用 `;`；路径用 `\` 或 `"` 包起来 |
| **Git Bash** | 路径用 `/`，`D:\projects` 写成 `/d/projects` |

本手册里的命令都是 **cmd / PyCharm Terminal** 风格。

### 5.3 临时设环境变量的三种写法

```bat
:: cmd / PyCharm Terminal
set TRIP_SCENARIO=campus
```
```powershell
# PowerShell
$env:TRIP_SCENARIO = "campus"
```
```bash
# Git Bash
export TRIP_SCENARIO=campus
```

设完再跑 `main.py` 就会默认用该场景（优先级：`--scenario` 参数 > 环境变量 > demo）。

### 5.4 `main.py` 全部 13 个参数

| 参数 | 取值 | 默认 | 示例 |
|---|---|---|---|
| `--scenario` | 场景名 | 环境变量或 `demo` | `--scenario campus` |
| `--strategy` | `stub` / `random` / 你新增的 | 场景配置里的 `default_strategy` | `--strategy greedy` |
| `--request` | JSON 文件路径 | 无 | `--request mock\case_basic.json` |
| `--query` | 一句自然语言 | 无 | `--query "预算 100 想去自然类的地方"` |
| `--days` | 整数 ≥1 | `1` | `--days 2` |
| `--start` | `"HH:MM"` | 场景 `day_start` | `--start 10:00` |
| `--end` | `"HH:MM"` | 场景 `day_end` | `--end 16:00` |
| `--budget` | 数字；`≤0` = 不限制 | 场景 `daily_budget` | `--budget 80` |
| `--top-n` | 整数（**每天**站数） | 场景 `max_poi_per_day` | `--top-n 3` |
| `--interests` | 逗号分隔 | 空 | `--interests 自然,拍照` |
| `--avoid` | 逗号分隔 | 空 | `--avoid 爬山` |
| `--pace` | `relaxed` / `normal` / `packed` | 场景 `default_pace` | `--pace packed` |
| `--out` | 输出 JSON 路径 | `outputs\plan_<场景>_<策略>.json` | `--out outputs\my.json` |

**优先级**：`--query` > `--request` 文件 > 默认值，最后再用上面的单项参数覆盖（单项永远最大）。

> ⚠️ `--out` 写相对路径时，基准是**项目根目录**，不是你现在所在的目录。

## 六、环境故障速查

### 6.1 `ModuleNotFoundError: No module named 'xxx'`

三种成因，按顺序排查：

1. **解释器不对**（九成是这个）→ 按 2.3 检查三处是否一致
2. 库真没装 → `Ctrl+Alt+S` → `+` 号装上
3. 装到了另一个 Python → `.venv\Scripts\python.exe -m pip list | findstr 包名` 确认

### 6.2 版本号与文档不一致

文档写"期望 `3.14.6 1.66.1 3.1.0`"，你是 `3.12.x` —— **不算错**。
只要 `main.py` 能跑、43 个测试全绿就没问题。版本号只是我开发时用的，不是硬要求。

### 6.3 git 提交身份没配

```bat
git config user.name "你的名字"
git config user.email "你的邮箱"
git log -1 --pretty="%an <%ae>"
```

两个人在同一个仓库用**同一个账号**提交，会让"个人贡献"无法区分 —— 所以队友要各自配自己的。

### 6.4 终端 / CSV 中文乱码

| 现象 | 原因 | 修法 |
|---|---|---|
| 终端里中文变成 `鍒嗗伐` | 终端编码是 GBK，输出是 UTF-8 | 换 PyCharm Terminal；或 `chcp 65001` |
| CSV 打开中文乱码 | 文件是 GBK | Excel「另存为 → CSV UTF-8（带 BOM）」 |
| 终端打印 `[warn] ... 解码失败` | 数据层在自动回退编码 | 不用管，程序会继续跑；但最好还是改成 UTF-8 |

### 6.5 Streamlit 页面白屏 / 404

1. 先看终端有没有 `Local URL: http://localhost:8501` —— 没有说明服务根本没起来
2. 有 URL 但页面白 → 按 `Ctrl+F5` 强刷
3. 页面显示 `ModuleNotFoundError` → 6.1
4. 端口被占 → 3.3

### 6.6 `.idea/misc.xml` 里 Black 写着 `Python 3.10`

这是 PyCharm 的历史残留，**不影响运行**。如果 Black 插件报"解释器无效"，把 `.idea/misc.xml` 里那行 `<option name="sdkName" value="Python 3.10 (ai-trip-planner)" />` 删掉，重启 PyCharm，它会按当前解释器重建。

### 6.7 `tomllib.TOMLDecodeError`

改 `config/scenarios/*.toml` 时最容易犯的三种错：

| 错法 | 对的写法 |
|---|---|
| `day_start = 09:00` | `day_start = "09:00"`（字符串要引号） |
| `weights = {satisfaction: 0.5}` | `[weights]` 换行 `satisfaction = 0.5` |
| 在 `[weights]` 下面直接写 `day_start = ...` | 表头之后的所有键都属于那张表，新的顶层键必须写在第一个表头**之前** |

### 6.8 `UnicodeDecodeError` 没被兜住

正常情况下 `data/loader.py` 会自动回退到 GBK。如果你看到它抛出来，说明回退逻辑被删了 —— 对照 `04` AC-21。

### 6.9 `streamlit: command not found`

Windows 上 `streamlit.exe` 不一定在 PATH 里。**永远用**：

```bat
.venv\Scripts\python.exe -m streamlit run ui/app.py
```

### 6.10 `fatal: not a git repository`

当前目录不是项目根。先 `cd /d D:\projects\ai-trip-planner` 再执行 git 命令。
