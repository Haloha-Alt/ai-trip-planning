# 14 · 从"一所学校"到"多所高校"：包结构、精度分级与两小时复刻

> 版本 v1.0 ／ 2026-11-02 ／ 回答一个问题：**这套东西怎么从大连理工一所学校，变成"能接任何一所学校"**。
> 前提不变：**小而精**。所以目标不是"覆盖 N 所学校"，而是"**把接一所学校变成一条 2 小时的流水线**"。

---

## 一、先改一个概念：单位不是"城市"，是"校区"

现在的结构有一个隐藏问题：

```
data/cities/dalian/pois.csv     ← 46 个点，其实全是"大连理工凌水校区"的点
```

大连还有海事、东财、大医……**第二所学校就没有地方放了**。城市这一层不够用。

### 1.1 目标结构（三包一层，向后兼容）

```
data/
├── cities/registry.toml              # 城市：中心点、别名（现有，保留）
└── campuses/                         # ★ 新增：校区才是真正的单位
    ├── dlut/
    │   ├── manifest.json             # 名称/所属城市/bbox/polygon/gates/level/sources/checksum
    │   ├── pois.csv                  # 点位（沿用现有 18 列表头，一列不改）
    │   ├── travel_matrix.csv         # 实测步行边
    │   └── base/
    │       ├── campus_map.json       # 栅格底图 + 仿射 6 参数（截图配准）
    │       └── tiles.json            # 瓦片 URL + 授权状态（有授权才写）
    └── dlmu/ …
```

**兼容策略**（很重要，不然 294 个测试要改一片）：

```toml
# registry.toml 里加一个字段，缺省即为 v1 行为
[cities.dalian]
campus = "campuses/dlut"     # 有就用校区包；没有就沿用 cities/dalian/pois.csv
```

加载顺序：`campus 包 → city 包 → 场景默认数据`。**缺什么降级什么，不许报错。**

### 1.2 为什么"校区"这个单位选对了

| 用"城市"当单位 | 用"校区"当单位 |
|---|---|
| 一座城市只能装一所学校 | 一座城市能装 N 所，通勤圈还能连起来 |
| 精度是"城市级"，说不清 | 每个校区各有等级，可以不一样 |
| 加学校 = 改城市包（会踩别人数据） | 加学校 = 新建一个目录，互不影响 |

## 二、精度分级 L0–L4：这套方案真正的护城河

不同学校能拿到的数据深度天然不同。**承认这件事，比假装一样精更有说服力。**

| 级别 | 手里有什么 | 能做什么 | 界面必须怎么写 |
|---|---|---|---|
| **L0** | 只有学校中心坐标 | 只有估算，几乎不可用 | "无数据包" |
| **L1** | 高德 POI ≥30 个 + 直线估算耗时 | 能排出顺序，时间不可信 | "点位：真实 / 耗时：估算" |
| **L2** | + 实测步行矩阵 ≥80 条边 | 时间可信，可以答辩 | "耗时：实测 N 条" |
| **L3** | + 校园栅格图配准（`campus_map.json`） | 地图能看懂在哪 | "底图：校园图（截图配准）" |
| **L4** | + 校方授权瓦片 | 地图是"官方的" | "底图：校园瓦片（已授权）" |

**当前大连理工 = L4 候选**（POI 46 + 实测 145 边 + 可申请瓦片），差的是那张授权。

### 2.1 两条硬规则

1. **等级必须显示在界面上**，右上角一个小徽标：`L2 · 实测 145 边`。低等级的学校，地图角落加"估算"水印。
2. **不许跨级吹**。L1 的学校不许在报告里写"精确步行时间"——这和你们"没核实就留空进待确认"是同一条纪律。

> 这条规则看着像自我限制，其实是**最强的可信度来源**：评委问"别的学校准不准"，你答"不准，我们标了 L1"，
> 比答"都很准"高级得多。

## 三、每个学校的数据从哪来（四条路，按性价比排）

| # | 来源 | 单校成本 | 覆盖 | 风险 |
|---|---|---|---|---|
| **1** | **校方 GIS 平台**（很多高校都有 `map.xxx.edu.cn` / "3D 校园"） | 探测 10 min + 配准 30 min | 中 | 需授权；部分学校平台要登录 |
| **2** | **高德 POI + 步行矩阵**（`tools/new_city.py` + `tools/amap_matrix.py` 已工具化） | **约 2 h** | **高**（任何学校都有 POI） | 配额；只能拿到"点"，拿不到"楼" |
| 3 | 官网 / 新生手册平面图（PDF、图片） | 配准 1 h | 中 | 图不规范、无比例尺 |
| 4 | 学生众包（本校学生用自己账号采） | 组织成本高 | 高 | 必须统一模板 + 验收，否则数据不可比 |

**默认走路线 2 打底，路线 1 加成。** 因为：路线 2 保证"任何学校都能跑起来"，路线 1 只决定"地图好不好看"。

## 四、先探测，再动手：5 分钟判断这所学校有没有公开平台

对目标学校，按顺序试（**每组只发 1–2 个请求，不批量取瓦片**）：

```text
① 域名试探（命中一个就停）
   map.<学校域名>          ／ 3dmap.<域名> ／ gis.<域名>
   <域名>/map  ／ <域名>/gis  ／ <域名>/3d
② 打开首页，看前端是什么
   Leaflet（找 leaflet.js / leaflet.css）  → 与 DLUT 同构，大概率有自家瓦片
   OpenLayers / ArcGIS API / SuperMap iClient / 天地图 API
③ 找可读的配置（这一步决定"能不能拿到瓦片"）
   /openmap/config/map-config.js ／ /config/map.js ／ /js/config.js
   在配置里搜：tileLayer、url:、wmts、lyrs、token、key
④ 判断瓦片归属
   指向 autonavi / tianditu / arcgisonline  → 底图是第三方的，没有"校方精细图"
   指向本域名下的 /map?lyrs= 或 /tiles/    → ★ 有自家精细瓦片（DLUT 就是这种）
⑤ 取 1 张瓦片验证（只要 1 张，判断是否 200 + image/png）
   有 → 记进 manifest.sources，标注"未授权，待申请"
   无 → 走路线 2/3
```

**把结论写进 `manifest.json`**，别写在脑子里：

```json
{
  "key": "dlut", "name": "大连理工大学（凌水主校区）", "city": "dalian",
  "bbox": [38.8808, 121.5252, 38.8880, 121.5332],
  "gates": ["西门", "北门", "南门"],
  "level": "L4",
  "sources": [
    {"kind": "poi", "tool": "new_city --fetch-pois", "count": 46, "date": "2026-11-03"},
    {"kind": "matrix", "tool": "amap_matrix", "edges": 145, "date": "2026-11-03"},
    {"kind": "basemap", "mode": "tile", "url": "http://map.dlut.edu.cn/map?lyrs=lm30&x={x}&y={y}&z={z}",
     "license": "pending", "note": "已发申请，未获批前默认关闭"}
  ],
  "checksum": "sha256:…"
}
```

## 五、两小时复刻清单（跑不进 2 小时，说明架构有问题）

| 时段 | 做什么 | 命令 / 工具 | 产物 |
|---|---|---|---|
| 0:00–0:10 | 探测平台（第四节） | 手工，1–2 个请求 | 结论：走路线 1 还是 2 |
| 0:10–0:25 | 建包骨架 | `python -m tools.new_city --scaffold <key> --name "<校名>" …` | 目录 + 空 pois.csv + registry 登记 |
| 0:25–0:55 | 抓 POI（**先 dry-run**） | `--fetch-pois <key> --keyword 教学楼 --keyword 食堂 --keyword 图书馆 --dry-run` | 看抓到的名字，删掉无关的，再去掉 dry-run |
| 0:55–1:25 | 拉步行矩阵 | `python -m tools.amap_matrix --city <key> --mode walk --max-km 2.0` | travel_matrix.csv（≥80 边） |
| 1:25–1:45 | 底图（二选一） | 有平台 → 截图 + `campus-calibrate.html` 配准；没平台 → 高德 JS API | `campus_map.json` 或 `tiles.json` |
| 1:45–2:00 | 体检 + 定级 + 截图 | `python -m tools.new_city --check`；写 manifest；截 3 张图 | 一个能装的校区包 |

**这就是"可复制性预算"**：它是衡量架构好坏的硬指标，比"支持多少城市"有用得多。
第一次做要 4 小时很正常（还在改工具），第三所开始就该压到 2 小时以内。

## 六、合规边界（跨校比本校更敏感）

| 情形 | 能不能做 | 说明 |
|---|---|---|
| 用高德 POI + 高德底图 | ✅ 可以 | **最稳的路**：高德有公开授权，标注即可 |
| 用 A 校的授权去接 B 校 | ❌ 不行 | 授权是**一校一份**，不能外溢 |
| 抓 B 校平台瓦片存进仓库 | ❌ 不行 | 与本校同理：权属 + 承载 + 答辩追问 |
| 学生用自己的账号采自己学校 | ✅ 可以 | 前提：本人访问公开页面、不转存、不代采 |
| 用第三方瓦片直连（autonavi 瓦片） | ❌ 不行 | 无授权、无 SLA，已在 `12` 第九节否掉 |
| 截图 + 配准 | ✅ 可以（校内教学） | 必须标注来源 + 日期 + 精度等级 |

**图上永远三行标注**：`数据来源 · 精度等级 · 获取日期`。这三行比任何免责声明都有用。

## 七、三阶段路线（对齐"小而精"）

| 阶段 | 做什么 | 出口条件 | 时间 |
|---|---|---|---|
| **P1 打磨模板** | 只做大连理工，把包结构、manifest、L0–L4、两小时清单**全部跑通并冻结** | 本校能装能卸；`--check` 全绿；manifest 字段不再改 | 现在 – 12 月初 |
| **P2 同城 2 所** | 选大连同城高校（海事 / 东财 / 大医 / 辽师，**是否都有平台待探测，别预设**） | 两所各出一个包；其中至少一所做到 L2；界面能切换学校 | 12 月 |
| **P3 跨省 3–5 所** | 只做"有学生愿意当数据志愿者"的学校 | 每所一份 manifest + 一次 `--check` 全绿 | 下学期 |

**明确不做**：全国覆盖。理由还是那句：300 所必然做糊，46 个点能做精。

### 7.1 答辩怎么说（一句话）

> "我们不是覆盖 N 所学校，而是把'接一所学校'做成了一条两小时的流水线：
> **装一个数据包就多一所学校，包里带精度等级，界面如实标。**
> 现在包里最强的是大连理工（L2 实测 + 校园图），弱的是别的学校——**弱的那部分我们标出来了，没有假装。**"

```text
【目标】manifest.level（L0–L4）一路透传到前端：右上角徽标"L2 · 实测 145 边"；

```

### T41 · 校园包探测与体检（挂进 preflight）

```text
【目标】tools/new_city 增加 --probe-campus <域名>：按第四节五步探测，输出一段可直接贴进
        manifest.sources 的 JSON；tools/preflight 增加"包完整性"检查
【探测只许发 1–2 个请求/组，命中即停；取瓦片最多 1 张用于判断类型】
【验收】① 对 dlut 域名探测，能识别出"Leaflet + 自家瓦片 + lyrs 参数"
        ② 对一个没有平台的教育域名，能明确输出"未发现公开平台"
        ③ preflight 对缺 manifest / checksum 不符的包报红
【禁区】不许写"遍历所有子域"的扫描器；不许批量拉瓦片做"预缓存"
```
**反模式**：它会写个并发扫描器把目标学校所有子域 404 一遍——那既慢又容易被当成扫描行为，直接否掉。
