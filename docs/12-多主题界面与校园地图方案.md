## 一、能不能抓校园地图：实测结果（2026-11-02 20:19，本机 + 校园网）

只发 5 个探测请求，不批量下载。原始记录：`design/_probe_map.json`。

| 探测对象 | 结果 | 耗时 | 判断 |
|---|---|---|---|
| `tile.openstreetmap.org`（瓦片 z16） | **超时** | 16.3 s | 国内网络基本不可达，**别指望** |
| `nominatim.openstreetmap.org`（地名检索） | **超时** | 16.4 s | 同上 |
| `restapi.amap.com`（高德 Web 服务，未带 Key） | **200**，返回 `INVALID_USER_KEY` | 140 ms | **线路通，只差 Key** ✅ |
| `webrd01.is.autonavi.com`（高德瓦片直连） | **200**，返回真 PNG | 166 ms | 技术上能抓，**但这是非授权用法，不做** ❌ |
| `t0.tianditu.gov.cn`（天地图 WMTS，未带 Key） | **418** | 1.2 s | 线路通，需申请 Key（免费、要实名） |
| `overpass-api.de`（OSM 要素查询） | **502** | 3.2 s | 不稳定，不能进生产 |

### 结论

**"抓"不是能力问题，是授权问题。** 三条路，按推荐顺序：

| 方案 | 怎么做 | 成本 | 合规 | 结论 |
|---|---|---|---|---|
| **A 高德 JS API（主）** | 控制台建 **Web端(JS API)** Key，绑域名白名单；`web/index.html` 已铺好开关，填 `AMAP_JS_KEY` 即生效 | 0 元，实名后即时下发 | ✅ 官方授权 | **主路径** |
| **B 天地图（备）** | 申请个人 Key，WMTS 瓦片，带审图号 | 0 元，1–2 天 | ✅ 国家平台，最"正" | 备选，A 挂了就换 |
| **C 离线示意（兜底）** | 用 46 个真实坐标 + 手描校区边界，SVG 画 | 0 元，已实现 | ✅ 自有数据 | **永远保留**，答辩断网靠它 |

> ⚠️ **明确不做**：`webrd01.is.autonavi.com` 这类瓦片直连虽然实测 166 ms 就返回了图片，
> 但它没有授权、没有 SLA、随时打水印或封 IP，老师们一问"这张图的版权是谁的"就答不上来。
> 你们自己在开题 PPT 里写过"爬取第三方瓦片 ✘ 不合规"——别在这里打自己的脸。

### 降级链（必须写死在代码里）

```
有 AMAP_JS_KEY 且 SDK 加载成功        → 高德真底图
    ↓ 超时 3s / 报错 / Key 失效
天地图 Key（若配了）                  → 天地图瓦片
    ↓ 也失败
离线 SVG（46 点 + 校区边界）          → 永远可用，状态栏注明"离线示意"
```

**关键**：降级不是"报错"，是"换一张纸"。用户永远能看到东西，只是角标从"高德"变成"离线示意"。

## 二、几套 UI 同时存在：怎么不把代码写成三份

### 2.1 三种实现方式，只有一种能用

| 做法 | 代价 | 结局 |
|---|---|---|
| ❌ 三份 HTML（`index.html` / `dash.html` / `map.html`） | 渲染逻辑×3、样式×3、bug×3 | 两周后三份开始不一样（改了一个忘了另两个），演示时"同一份数据两个界面两个数" |
| ⚠️ 只换配色（三套 CSS 变量） | 便宜 | 用户感觉不到"三套界面"，只像换了个暗色模式 |
| ✅ **一套 DOM + 三套 token + 三套布局类** | 一次改造，之后零成本 | 三个界面、一份渲染逻辑、一份测试 |

### 2.2 具体怎么切

```
<html data-theme="paper">     ← 只切这个属性
```

| 层 | 用变量控制 | 用布局类控制 |
|---|---|---|
| 颜色 / 字体 / 圆角 / 线 | `--paper --ink --accent --rule --mono` | — |
| 主轴 / 旁注 / 地图 的排布 | — | `grid-template-columns` |
| 元素显隐（如"图"主题隐藏旁注） | — | `display:none` 一条规则 |

三套主题的定位（不能只是颜色不同，**每套要有自己的用途**）：

| 主题 | 给谁用 | 差别不只是颜色 |
|---|---|---|
| **纸**（默认） | 打印、截图、交作业 | 时间轴是主视图，旁注在右，米白纸感 |
| **暗** | 晚上在宿舍看、投屏演示 | 深色、对比更强、块变成实心条 |
| **图** | 想先看"在哪"的人 | 地图常驻右侧（钉住），轴收窄，旁注隐藏 |

> **硬规则**：三套主题都必须能完成**全部**操作（生成 / 看轴 / 看地图 / 导出）。
> 任何一套缺功能，就不算"同时使用"，只是"三个半成品"。

### 2.3 记住选择、可深链

- 切主题写 `localStorage`，下次打开还是那套；
- 支持 `?theme=paper|dash|map`，方便 PPT 里放三个链接直接跳到三个界面；
- 首次访问默认"纸"。

## 三、地图按钮：怎么做到"随叫随到"

### 3.1 交互定稿

| 元素 | 规格 |
|---|---|
| 触发 | 右下角常驻浮标「地图」，44×44 起，`position:fixed`，任何滚动位置都在 |
| 快捷键 | `M` 开关，`Esc` 关闭（输入框聚焦时不抢键） |
| 形态 | **抽屉**（右侧 420px 滑出），**不是第 5 个页签**——页签会把主视图切成碎片 |
| 钉住 | 抽屉内「钉住」→ 主体右移 420px，边看轴边看地图（"图"主题默认钉住） |
| 联动 | 点轴上的站 → 地图上对应 pin 放大变墨色；点地图 pin → 轴上对应块加红边 |
| 底图 | 三个小按钮：离线示意 / 高德底图；状态行写清"当前用的是哪张纸" |
| 手机 | ≤900px 抽屉全屏，关掉回到轴 |

### 3.2 为什么是抽屉而不是页签

页签的隐含语义是"你要么看这个、要么看那个"；而地图的用法是**"我在看行程，顺手确认一下位置"**。
抽屉 + 钉住两种状态，正好覆盖这两种用法，且不增加一个并列主视图。

### 3.3 已做成可点的原型

`design/mock-multitheme.html`（双击即开，零依赖）：

- 右上角三个小按钮切换 **纸 / 暗 / 图**；
- 右下角「地图 M」打开抽屉；「钉住」把地图固定到右侧；
- 地图用**真实 POI 坐标**（伯川图书馆、第三食堂、菜鸟驿站、刘长春体育馆）+ 手描校区边界 + 150m 比例尺；
- 点轴上的站，地图 pin 会跳出来；
- 点「高德底图」，状态行如实变成"未配 Key，已回退离线示意"。

## 四、以大连理工为实验点：现在有什么、还缺什么

### 4.1 已经有（不用再造）

| 项 | 现状 |
|---|---|
| 校区点位 | **46 个**，`data/cities/dalian/pois.csv` 里**已经是凌水主校区场景**：伯川/令希图书馆、四个食堂、刘长春体育馆、游泳馆、校医院、菜鸟驿站、校车站…… |
| 坐标 | 每条都有 `lat/lon`，主校区密集区约 **38.8818–38.8874 / 121.5268–121.5318**（约 780m×550m） |
| 步行耗时 | **145 条**高德实测边 |
| 归属 | `address` 字段已按"凌水主校区西部/中部/北部、西山生活区、北山生活区、校区南门外"分区 |

> 也就是说：**"以大连理工为实验点"这件事，数据层已经完成 80%**，缺的不是点，是"边界的形状"和"地图的取景"。

### 4.2 要补的四样（最小集，一天能做完）

| # | 补什么 | 怎么补 | 放在哪 |
|---|---|---|---|
| 1 | **校区边界**（10–20 个顶点的多边形） | 高德 JS API 的 `AMap.Polygon` 手点一圈，导出经纬度；或用校方公开平面图对照描 | `data/cities/dalian/campus.json` |
| 2 | **校门**（西门 / 北门 / 南门 / 西南门） | 补 3–4 条 POI，`category=校门`，`stay_min=0` | `pois.csv` 追加 |
| 3 | **分区归属**（校内 / 周边 / 校外） | 用"点是否在多边形内"判定，写进新字段 `zone`（只增不改） | `campus.json` + 加载时计算 |
| 4 | **取景参数**（bbox + 默认 zoom） | 由边界算 bbox，zoom 固定 16 | `campus.json` |

有了这四样，"地图"才能做三件事：**自动取景、按区域着色、判断"这一站在校内还是校外"**（后者直接影响步行时间估算的可信度）。

### 4.3 实验点的演示口径（写给答辩用）

> "我们把大连理工凌水主校区当作一个**可以量到底**的实验场：46 个点、145 条实测步行耗时、
> 一条手描的校区边界。**换城市不是改代码，是装一个数据包**——这就是为什么先做深一个点。"

## 五、任务卡 T32–T37

> 承接 T20–T31。老规矩：一卡一事、可运行判据、写禁区、写反模式。

### T32 · 主题系统骨架（一套 DOM，三套 token）

```text
只改 CSS 与一个极小的初始化函数，不改任何渲染逻辑、不改接口调用。

【目标】把 web/index.html 的样式全部 token 化：颜色/字体/线宽/圆角走 CSS 变量，
        挂到 <html data-theme="paper|dash|map">；右上角加三个 30×22 的切换按钮
【约束】① 不许复制三份 HTML ② 不许改任何 renderXxx() 函数 ③ 不许引入 CSS 框架
        ④ 主题切换必须 <100ms，且写 localStorage、支持 ?theme= 深链
【验收】① 三套主题各截一张 1280px 图 ② 切主题后页面不重排跳字（同一元素 offsetTop 差 <2px）
        ③ node _render_check.js 13 项仍全绿
【禁区】不许在 JS 里写颜色值（只许 data-theme 切换 + CSS 变量）
```
**反模式**：它会给你写三套独立 CSS 文件并在切换时替换 `<link>` —— 维护立刻变三份。

### T33 · 三套主题都必须"能干活"

```text
这是验收卡，不是开发卡：把三套主题各走一遍完整流程。

【目标】对 paper / dash / map 三套，各自完成：填需求 → 生成 → 看轴 → 开地图 → 导出
【验收】三套主题 × 五个动作 = 15 张截图，缺一张算没做完；
        任何一套出现"按钮被遮住 / 文字溢出 / 无法关闭抽屉"，当场修，不许记 TODO
【禁区】不许用"这套主题只是展示用"来解释缺失功能 —— 那就不是三套界面，是三个半成品
```

### T34 · 地图抽屉：常驻、可钉住、双向联动

```text
【目标】右下角常驻浮标（fixed，44px 高，含 M 键提示）→ 点开右侧 420px 抽屉；
        抽屉内"钉住"让主体右移 420px；Esc 关闭；M 键开关（input 聚焦时不抢）
【联动】点轴上的站块 → 地图对应 pin 半径 7.5→10、颜色转墨；
        点地图 pin → 轴上对应块加 1px 红边（同一份 select(poiId) 函数，不许写两套）
【约束】抽屉用 transform:translateX 动画（≤300ms），不许用 display 切换（会闪）
【验收】① 任意滚动位置浮标可见 ② 打开到可见 ≤300ms ③ pin 数 == 站点数
        ④ 点 4 个站，4 次都高亮正确 ⑤ 375px 下抽屉全屏且能关
【禁区】不许做成第 5 个页签；不许让抽屉遮住"重排"按钮（遮住就改尺寸）
```
**反模式**：它会用 `position:absolute` 挂在内容流里 —— 滚两屏就找不到了，那就不是"随时"。

### T35 · 底图降级链与状态如实显示

```text
【目标】三级降级：AMAP_JS_KEY 有值→高德底图；失败/3s 超时→天地图（若配 Key）→离线 SVG。
        抽屉顶部固定一行状态："底图：高德 / 天地图 / 离线示意（未配 Key）"
【约束】降级只能发生一次（不许来回抖）；失败必须 console.warn 一行原因；
        不许把 Key 写进前端常量（从 /api/options 的 map.js_key 读）
【验收】① 无 Key：状态显示"离线示意"，页面无红色报错 ② 故意填错 Key：3s 内自动回退
        ③ 断网：仍能画离线图
【禁区】不许静默失败（"点了没反应"是最差体验）；不许用 fetch 直连高德瓦片域名
```
**反模式**：它会 `try{...}catch(e){}` 吞掉错误，结果你永远不知道 Key 是不是生效了。

### T36 · 校园数据最小集（边界 / 校门 / 分区）

```text
【目标】① 新增 data/cities/dalian/campus.json：{"bbox":[...], "polygon":[[lat,lon],...],
        "zoom":16, "gates":["西门","北门","南门"]}
        ② pois.csv 追加 3–4 条校门（category=校门，stay_min=0）
        ③ 加载时算 zone：点在多边形内→campus，否则→off_campus（只加字段，不改既有字段）
【约束】campus.json 是数据不是代码；引擎与数据层仍零第三方依赖
        （点在多边形内用射线法，自己写 10 行，不许装 shapely）
【验收】① tools 里加一条校验：46 点中 campus 多少、周边多少，打印出来
        ② 新增单测：已知 3 个点（伯川图书馆=校内、星海广场=校外、地铁站=校外）
【禁区】不许把边界写死在前端 JS 里；不许用第三方几何库
```
**反模式**：它会装 `shapely` 或 `geopandas` —— 你们两个在开题里刚说过"换机不能炸"，别自打脸。

### T37 · 取景、比例尺与"图"主题的排版

```text
【目标】① 地图自动 fit 到 bbox（含留白），zoom 按窗口宽度算，不许写死 16
        ② 画指北针 + 比例尺（按当前 zoom 换算，误差 <10%）
        ③ "图"主题：地图默认钉住，主轴收窄到 760px，旁注隐藏但"跳过的点"必须保留
【约束】投影用等距圆柱近似（本校 550m 尺度误差 <0.3%，够用），不许引投影库
【验收】① 1280 / 900 / 375 三个宽度各截一张，地图都不裁剪点位
        ② 比例尺与真实距离比对（用两个已知点：伯川图书馆→第三食堂 实测步行 6′）
【禁区】不许把点位连成"折线"就当地图 —— 必须有边界、比例尺、指北针，否则不像地图
```

## 九、i大工 /「3D校园」那张精确图，到底能不能用（实测）

### 9.1 平台是什么（探测 2026-11-02 22:37）

| 事实 | 依据 |
|---|---|
| 学校有官方 GIS 平台 **`http://map.dlut.edu.cn`**（"校园地图服务系统"，网络与信息化中心 2015 年起建的「3D 校园」） | 首页 200，`nginx/1.10.2`，返回 1626 字节 SPA 骨架 |
| 前端是 **Leaflet** | `/openmap/config/map.css` 就是 Leaflet 样式表 |
| 常规底图是**高德瓦片** | `map-config.js`：`wprd02.is.autonavi.com/appmaptile?...style=7`、`webst04...style=6/8` |
| **14–19 级叠加了校方自家瓦片** | `url:"/map?lyrs=last&x={x}&y={y}&z={z}"`（14–17 级）、`url:"/map?lyrs=lm30&x={x}&y={y}&z={z}"`（13–19 级） |
| 自家瓦片**没有鉴权** | 取 `z=16&x=54891&y=25073&lyrs=lm30` → **200 / image/png / 125 KB / 256×256**，画面是带屋顶、道路、绿化、操场的精细建筑图 |

> `lyrs=last` 在 z=17 返回 404 —— 两个图层覆盖层级不同，接入时要各试一次。

### 9.2 判断：**技术上能用，规矩上不能直接拿**

1. **能取到，但没有授权。** 无鉴权 ≠ 可自由使用；这套瓦片是学校出钱测的，属校方资产。
2. **它不是给人刷的。** 单张 125 KB、老版本 nginx，几十人同时拉就会拖垮；答辩现场卡的不会是你的网速，是网信中心的服务器。
3. **答辩一定会被问"图哪来的"。** 答"从学校地图扒的"是硬伤；答"已申请、仅校内演示、页面标注来源"是加分。

### 9.5 配套工具：三点配准器（已做好，双击即用）

`design/campus-calibrate.html`（零依赖，离线）：

1. 「选择图片…」载入截图（或点「合成示例」先跑一遍流程）；
2. 左侧下拉选一个"你确定它在图上哪"的点 → 在图上点它的位置；
3. 3 个点能开算，**第 4 个点才开始检验误差**（3 点必然零残差，因为 6 个参数刚好定完）；
4. 显示**均方根残差**，< 5px（1600px 宽图上约 3 米）就能用；
5. 「导出 campus_map.json」+「导出叠加图」（可直接进 PPT）。

导出的 JSON，后端/前端都能直接消费：

```json
{
  "image": "campus.png", "width": 1600, "height": 1100,
  "affine": {"a": -0.000215, "b": 0.000004, "c": 121.64,
             "d": 0.000003, "e": 0.000221, "f": -38.79},
  "control_points": [{"poi_id":"DL003","px":812,"py":433}],
  "rms_px": 4.53,
  "note": "px = a*lon + b*lat + c ; py = d*lon + e*lat + f",
  "source": "校园地图服务系统截图（校内教学使用，须标注来源与日期）"
}
```

> 这就是"校园底图插件"的第一步：**一张图 + 6 个数 = 一个可用底图**，不依赖任何在线服务，断网也画得出来。
