## 一、核实纪律（三个人一起守）

| 规则 | 说明 |
|---|---|
| 一行一来源 | `url` 填官方页/地图 POI 页；没有可靠来源就留空，不要编 |
| 只有核对过才填日期 | 实地或官方页确认后，把 `source_date` 写成 `YYYY-MM-DD` |
| 拿不准就留空 | 开放时间/价格不确定时留空，走 `POI` 默认值（00:00–23:59 / 0 元） |
| 改数据必须改本表 | 同一次提交里一起改，防止表和 CSV 对不上 |
