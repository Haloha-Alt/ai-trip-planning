# 06 · 内网穿透与分享（让同学/评委打开你的网站）

> 面向场景：**答辩现场要把网页给评委看**、**把链接发给不在同一 Wi-Fi 的同学**。
> 前置阅读：`README.md` 的「二·五、让别人也能打开」。
> 本文只讲一件事：怎么把 `127.0.0.1:8000` 变成一个**谁都能点开的地址**。

---

## 一、先搞清楚：为什么"直接发个 HTML"不行

这个网站不是一个文件，是**前端页面 + Python 后端**：

| 组成 | 在哪 | 少了它会怎样 |
|---|---|---|
| 页面（四页签、地图、时间轴） | `web/index.html` | 打开是白板 |
| 规划引擎 | `engine/` | 点了"生成行程"没反应 |
| 数据（46 个点 + 实测路网） | `data/` | 没有可排的站点 |
| 大模型调用 | `llm/` + `.env` 里的 Key | 解说退回规则模板（仍可用） |

所以"把 HTML 传到 GitHub Pages"这条路是死的：Pages 只发静态文件，
上面三样都没地方跑；而且 Key 必须留在服务端，放到前端等于公开。
详见 `README` 的「GitHub Pages 为什么不行」。

**结论**：要"别人打开就能用"，必须有一台机器**正在跑这个后端**。两条路：

- **A 内网穿透**（本文重点）：跑在你自己电脑上，用隧道把它映射成公网地址。零成本、5 分钟。
- **B 部署到服务器**：跑在校内服务器或云主机上。稳定、但要一台机器和运维。

## 二、走之前先做 3 项检查（30 秒）

```bash
# 1) 服务在跑吗（窗口里应该有监听提示；Ctrl+C 就停了）
.venv\Scripts\python.exe -m api.server

# 2) 本地通不通
.venv\Scripts\python.exe -m tools.share_link --check

# 3) 大模型通不通（穿透之后云端也要能调模型，别只验首页）
.venv\Scripts\python.exe -m tools.llm_probe --narrate
```

> 第 3 步很关键：**能打开网页 ≠ 能生成行程**。
> 大模型网关 `aigw.dlut.edu.cn` 若只对校园网放行，你在校外用流量打开网页也会在"生成解说"这一步卡住。

## 三、cpolar 实战（推荐，国内网络可用）

### 3.1 注册与安装

1. 打开 https://www.cpolar.com ，注册账号（免费版够用）
2. 下载 Windows 版并安装（默认下一步即可）
3. 装完浏览器会打开本地管理页 `http://127.0.0.1:9200`，用刚注册的账号登录

### 3.2 拿到并写入 authtoken（只需做一次）

登录后进「验证」页，复制那串 `authtoken`，在 PowerShell 里执行一次：

```powershell
cpolar authtoken 你的authtoken
```

看到 `Authtoken saved` 就成功了，以后不用再管。

### 3.3 起两条命令（两个窗口，都别关）

**窗口 1 — 先把网站跑起来：**

```powershell
cd D:\projects\ai-trip-planner
.venv\Scripts\python.exe -m api.server
```

或者直接双击 `分享给他人.bat`（它会带上 `WEB_HOST=0.0.0.0` 和访问口令）。

**窗口 2 — 开隧道：**

```powershell
cpolar http 8000
```

窗口里会出现一张 `Forwarding` 表，抄下 `https://` 开头那个地址，形如：

```
https://3f2a-1c-58-9d.r3.cpolar.cn
```

> 免费版是**随机域名，每次重启都会变**。别把它写死在文档里，现抄现用。

### 3.4 生成"能直接发人"的链接并自检

```powershell
.venv\Scripts\python.exe -m tools.share_link https://3f2a-1c-58-9d.r3.cpolar.cn --check
```

输出里会有一条 `公网 … [OK] HTTP 200`，那就是可以发的链接（已自动拼上口令）：

```
https://3f2a-1c-58-9d.r3.cpolar.cn/?code=你的口令
```

**看到 `[OK]` 再发人**。没 OK 时它会告诉你卡在哪层，见第五节。

### 3.5 发给别人

一条链接，带口令，对方点开即用（前端会自动记住口令，不弹框）。

## 四、安全底线（穿透 = 把一个"无限额度 Key 的代理"挂到公网上）

学校网关的令牌是**无限额度**的公共资源，泄漏了别人能一直用，责任算在你头上。
所以对外开放时**必须**做到：

| 要做 | 为什么 |
|---|---|
| `ACCESS_CODE` 一定要设（`分享给他人.bat` 里已有） | 没有口令 = 任何人拿到地址都能烧额度 |
| Key 只在 `.env`（已被 `.gitignore` 排除） | 前端代码是发给浏览器的，里面不能有任何密钥 |
| 用完就关窗口 | 隧道和网站都停掉，地址立刻失效 |
| 不要把地址写进公开仓库/群相册 | 免费域名会变，但口令不会 |

## 五、故障对照表（按现象查）

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 本地 `127.0.0.1:8000` 都打不开 | 服务没起 / 端口被占 | 先起服务；`netstat -ano | findstr 8000` 看占用 |
| 首页能开，点"生成行程"报错 | 口令没生效 | 用带 `?code=` 的完整链接；或看 `--check` 的 401 提示 |
| 公网地址打开是 cpolar 的提示页 | 隧道没连上本地端口 | 确认窗口 1 在跑、端口是 8000 |
| 公网 502 / 超时 | 隧道开了但本地服务停了 | 重启窗口 1 |
| 别人打开正常，但没解说 | 大模型没通（校外访问不到网关） | `python -m tools.llm_probe --narrate` |
| 手机连同一 Wi-Fi 打不开内网地址 | **校园网终端隔离** | 见 `README` 二·五；改用热点或直接走穿透 |

> 校园网 `DLUT-LingShui 2` 实测有终端隔离：防火墙已放行 python 也没用，
> 同 SSID 的设备互相访问不到。**这不是你配错了**，所以内网方案在校园网下经常失效，
> 穿透才是稳的那条。

## 六、其他穿透工具（备选）

| 工具 | 适合 | 注意 |
|---|---|---|
| **cpolar** | 国内网络、有免费版 | 随机域名会变；免费版有带宽/隧道数限制，以官网为准 |
| **Cloudflare Tunnel（cloudflared）** | **免费、带宽慷慨、可固定域名** | 临时域名每次重启会变；固定域名要先把域名托管到 Cloudflare |
| **花生壳** | 国内老牌，有 Windows 客户端 | 免费版域名更受限，映射 HTTP 需要配置 |
| **frp** | 你**自己有一台云服务器** | 最稳、可固定域名；需要 server + client 两端配置 |
| **ngrok** | 国外资料多 | 国内经常连不上，不建议现场用 |

三条路的命令差别只在"开隧道"那一步；**之后的 `tools.share_link --check` 完全通用**。

## 六之补、使用量很小、暂时不想买服务器怎么办

**先记一条铁律：后端不能搬走，只能换"门"。**

网关按来源 IP 放行。后端一旦跑在校外机器（尤其境外 PaaS），`/api/plan` 就调不到大模型 ——
页面能开、一点生成就退回规则，**看着能用其实是坏的**。所以"免费云平台"这条路基本是死的。

| 方案 | 成本 | 别人用流量能开 | 模型还能调 | 结论 |
|---|---|---|---|---|
| **Cloudflare Tunnel 临时域名** | 0 元 | 能 | 能（后端还在你电脑） | **最推荐的"将就"方案**：一条命令、不用注册 |
| **Cloudflare Tunnel + 自有域名** | 域名 ~10 元/年 | 能，且地址固定 | 能 | 想要稳定地址就花这点钱，比服务器便宜两个数量级 |
| cpolar 免费版 | 0 元 | 能 | 能 | 国内可连，但域名会变、带宽紧 |
| Render / Railway / Fly.io 免费档 | 0 元 | 能 | **大概率不行** | 别白折腾；免费档还会休眠，冷启动 30 秒起 |
| 学校 / 实验室的服务器 | 0 元 | 能 | 能 | **最容易被忽略**，问导师或学院机房，可能现成就有 |
| 自己电脑 + 校园网 IP | 0 元 | 不能 | 能 | 校园网终端隔离，同 Wi-Fi 都连不上，只适合自己用 |

### Cloudflare Tunnel 怎么用（零成本）

```powershell
# 1) 装一次（也可去官网下 cloudflared.exe）
winget install --id Cloudflare.cloudflared

# 2) 另一个窗口把网站跑起来，别关
.venv\Scripts\python.exe -m api.server

# 3) 开隧道，不用注册账号
cloudflared tunnel --url http://localhost:8000
```

会打印一个 `https://xxxx-yyyy.trycloudflare.com`，和口令拼起来发给别人：

```
https://xxxx-yyyy.trycloudflare.com/?code=你的口令
```

- 优点：免费、带宽比 cpolar 免费版宽松、不用注册、天然 https
- 缺点：`trycloudflare.com` 是**临时域名，进程一停就失效、重启会变**；
  官方明说它不适合长期生产 —— 但"将就几周"完全够
- 想让地址固定：域名托管到 Cloudflare（免费套餐），再建 named tunnel：
  `cloudflared tunnel create trip` → `cloudflared tunnel route dns trip 你的域名`

### 无论走哪条，这三件事别省

1. **`ACCESS_CODE` 必须设** —— 隧道等于把入口开到公网，没口令谁都能烧你的额度
2. **窗口别关** —— 隧道和本地服务关一个，网站就没了（这也是它只能"将就"的原因）
3. **发人之前跑一次** `python -m tools.share_link https://你的隧道地址 --check`，看到 `[OK]` 再发

## 七、答辩当天的建议顺序

1. 提前一天：`python -m unittest discover -s tests -t .`（应 283 全绿）
