# 使用手册

> 面向第一次拿到这个项目的人。照着做就能跑起来。

## 一、第一次拿到项目

```bash
# 1. 用 PyCharm 打开项目根目录（不是某个 .py 文件）
#    File → Open → D:\projects\ai-trip-planner

# 2. 确认解释器指向项目自己的 .venv
#    Settings (Ctrl+Alt+S) → Project → Python Interpreter
#    应显示 D:\projects\ai-trip-planner\.venv\Scripts\python.exe
#    如果不是：Add Interpreter → Virtualenv → Existing → 选上面那个路径

# 3. 环境自检（PyCharm 底部 Terminal，Alt+F12）
.venv\Scripts\python.exe -c "import sys,streamlit,pandas;print(sys.version.split()[0], streamlit.__version__, pandas.__version__)"
```

期望输出：`3.14.6 1.66.1 3.1.0`

## 二、三条命令

| 想干什么 | 命令 |
|---|---|
| **命令行跑通整条链路** | `.venv\Scripts\python.exe main.py` |
| **打开网页界面** | `.venv\Scripts\python.exe -m streamlit run ui/app.py` |
| **跑测试，确认没坏** | `.venv\Scripts\python.exe -m unittest discover -s tests -t . -v` |

补充：

```bash
# 用某个 mock 用例跑
.venv\Scripts\python.exe main.py --request mock/case_tight.json

# 换算法
.venv\Scripts\python.exe main.py --strategy random

# 自然语言输入
.venv\Scripts\python.exe main.py --query "想走走自然类的地方，预算 100 元，别太赶"

# 跑基线对比（所有策略 × 所有用例）
.venv\Scripts\python.exe -m eval.baseline
```

`main.py` 的结果会打印到终端，**并落盘到 `outputs/plan_<场景>_<策略>.json`**（`outputs/` 不进 git）。

## 三、在 PyCharm 里怎么点

| 操作 | 做法 |
|---|---|
| 跑 `main.py` | 左侧文件右键 → `Run 'main'`；参数在 Run/Debug Configurations → Parameters 里填，如 `--strategy random` |
| 跑 Streamlit | `Run → Edit Configurations → + → Python`，**Module name** 填 `streamlit`，**Parameters** 填 `run ui/app.py`，**Working directory** 填项目根 → 保存后点绿三角 |
| 跑测试 | 左侧 `tests` 目录右键 → `Run 'Unittests in tests'` |

⚠️ **不要**对 `ui/app.py` 直接点绿色三角 —— 页面不会出来。
⚠️ **不要**单独运行 `engine/*.py` —— 它们是被调用的模块，不是入口。

## 四、改东西在哪改

| 你想改什么 | 改哪个文件 | 要不要动 Python 代码 |
|---|---|---|
| 预算、时间窗、权重、交通方式 | `config/scenarios/demo.toml` | 不需要 |
| 换一整套场景 | 复制 `config/scenarios/template.toml` → 改名 → `--scenario xxx` | 不需要 |
| POI 清单、标签、坐标 | `data/pois.csv` | 不需要 |
| 两点间的距离/耗时 | `data/travel_matrix.csv`（可以只填一部分） | 不需要 |
| 兴趣词 → 标签的映射 | `demo.toml` 的 `[interest_alias]` 段 | 不需要 |
| **规划算法** | `engine/strategies.py` | 见下 |
| 硬约束、评分公式 | `engine/constraints.py` | 需要 |
| 距离/时间/费用怎么算 | `engine/geo.py` | 需要 |
| 页面排版 | `ui/render.py` | 需要 |
| 页面控件 | `ui/app.py` | 需要 |

### 怎么加一个新算法（三行）

在 `engine/strategies.py` 里：

```python
def greedy_plan(req: PlanRequest, cfg: ScenarioConfig) -> PlanResponse:
    pool, wanted = _candidate_pool(req, cfg)     # 1. 拿候选
    # 2. 你的算法：挑哪些点、按什么顺序
    picked = my_smart_pick(pool, wanted, cfg)
    day = _fill_day(picked, req, cfg, wanted)    # 3. 铺时间轴（复用现成的）
    return PlanResponse(request=req, days=[day])

STRATEGIES["greedy"] = greedy_plan               # 注册即可
```

注册完立刻可用：命令行 `--strategy greedy`、网页下拉框里会出现、`eval/baseline.py` 会自动把它纳入对比。**引擎、UI、评测一行都不用改。**

## 五、换场景的完整步骤

1. 复制 `config/scenarios/template.toml` → 改名成你的场景名，比如 `campus.toml`
2. 填 `day_start` / `day_end` / `daily_budget` / `max_poi_per_day` / `[weights]`
3. 填 `[interest_alias]`：左边用户会说的词，右边 `data/pois.csv` 里的标签
4. 改 `data/pois.csv`：换成真实 POI（用 Excel 编辑，**另存为 CSV UTF-8 带 BOM**）
5. 可选：在 `data/travel_matrix.csv` 填你有把握的几条边，其余自动估算
6. 验证：

```bash
.venv\Scripts\python.exe main.py --scenario campus
.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
```

**整个过程中 Python 代码零改动** —— 这是本项目的核心设计目标。

## 六、git 存档

当前只有本地提交，没有远程仓库。每个阶段跑通就提交一次：

```bash
git status                 # 看改了哪些文件
git add <文件或目录>         # 不要用 git add . ，容易把 .venv/.idea 带进去
git commit -m "feat(xxx): 一句话说明"
git log --oneline          # 确认提交成功
```

commit message 用 Conventional Commits：`feat` / `fix` / `docs` / `chore` / `refactor` / `test`。

### 以后接 GitHub

```bash
git remote add origin https://github.com/<用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

顺序永远是：**我写代码 → 本地跑通 → commit → push**。GitHub 是存档室，不是工作台。

## 七、常见报错对照表

| 报错 / 现象 | 原因 | 怎么修 |
|---|---|---|
| `ModuleNotFoundError: No module named 'streamlit'` | 装到了别的 Python 上 | 用 PyCharm 的 `Settings → Python Interpreter → +` 重装，别在终端裸跑 `pip install` |
| 网页打不开 / 命令不识别 | 对 `ui/app.py` 点了绿三角 | 用 `python -m streamlit run ui/app.py` |
| `ModuleNotFoundError: No module named 'engine'` | 运行目录不对 | 确认工作目录是项目根；`main.py` 已自动处理，`ui/app.py` 也已加 `sys.path` |
| CSV 中文全是乱码 | 存成了 GBK | Excel 另存为「CSV UTF-8（带 BOM）」 |
| 改了 CSV 但页面没变 | 数据层有缓存 | 点侧边栏「清空数据缓存」，或重启 Streamlit |
| `未知策略 'xxx'` | 名字没注册 | 看 `engine/strategies.py` 的 `STRATEGIES` 字典 |
| `git status` 里出现 `.idea/` `.venv/` | 用了 `git add .` | 先 `git rm -r --cached .idea`，再按文件逐个 add |
| 提交时提示 LF/CRLF warning | Windows 换行差异 | 已设 `core.autocrlf=true`，只是提示，不影响 |
