## C、想要一个**不会再变**的地址（推荐，约 10 元/年）

`253e175f.r8.cpolar.cn` 这种免费随机域名，**重启隧道就会变**，发出去就失效。

- [ ] **C1** 买一个域名（阿里云/腾讯云都行，`.top`/`.xyz` 首年 10 元上下）
- [ ] **C2** 把域名托管到 **Cloudflare**（免费套餐，改 NS 记录即可）
- [ ] **C3** 装 cloudflared：`winget install --id Cloudflare.cloudflared`
- [ ] **C4** 建固定隧道：

      ```powershell
      cloudflared tunnel login
      cloudflared tunnel create trip
      cloudflared tunnel route dns trip 你的域名
      cloudflared tunnel run --url http://localhost:8080 trip
      ```

- [ ] **C5** 之后地址永远是 `https://你的域名/?code=trip-8261`

> 为什么不用 cpolar 绑自有域名：那个能力在**付费套餐**里。想把成本压到 10 元/年，走 Cloudflare。
